三角関数の周期・平行移動と、方程式の解の個数

(1) ① 関数 y = 2cos x の周期のうち、正で最小のものを求めよ。 　　② 関数 y = 2cos 2x の周期のうち、正で最小のものを求めよ。 　　③ 次の等式を利用して、関数 y = 2cos(2x + π3) のグラフが、関数 y = 2cos 2x のグラフを x軸方向にどれだけ平行移動したものか答えよ。　2cos(2x + π3) = 2cos 2(x + π6) (2) グラフを利用して、方程式 sin x = 2cos(2x + π3) の解の個数を求めよ。 　　① 0 ≦ x ≦ π　　② 0 ≦ x ≦ 2π

(1)　周期は x の係数で決まる（2π ÷ 係数）→ 平行移動は「x − p」の形にして読む (2)　2つのグラフをかく → 重ねて交点を数える → 方程式の解の個数
この問題の合言葉：「周期は 2π ÷ x の係数」「平行移動は x の係数でくくってから読む」「方程式の解の個数は、グラフの交点の個数」。
(1)①
周期

y = 2cos x の周期

関数 y = 2cos x の周期のうち、正で最小のものを求めよ。

y = a cos(bx + c) の　周期 ＝ 2π｜b｜　　振幅 ＝ ｜a｜ cos x の周期は 2π（sin x も同じ）
cos x の周期は 2π である。 y = 2cos x は、cos x の値を 2倍しただけ（波の高さが変わるだけ）なので、周期は変わらない。 よって、正で最小の周期は 2π
やさしい解説：周期と振幅

周期は「同じ形がくり返す、1回分の横の長さ」です。振幅は波の高さ（真ん中から山までの高さ）です。

前につく 2 は、グラフを縦に 2倍に引きのばすだけ（振幅が 1 → 2）。横の長さは変わらないので、周期は 2π のままです。

テストのポイント：前の係数 2 は振幅（高さ）。周期に関係するのは x にかかる係数だけです。2 を見て「周期が変わる」と考えないこと。
答 (1)①2π
(1)②
周期

y = 2cos 2x の周期

関数 y = 2cos 2x の周期のうち、正で最小のものを求めよ。

y = cos kx の周期 ＝ 2π｜k｜
y = 2cos 2x は y = cos kx の形で k = 2 なので、周期は 2π2 = π
やさしい解説：なぜ周期が半分になる？

cos 2x では、x が進むと「2x」はその2倍の速さで進みます。x が 0 から π まで進むと、2x は 0 から 2π まで進んで、cos が1回分の波を終えます。だから周期は π（もとの半分）です。

確かめ：2cos 2(x + π) = 2cos(2x + 2π) = 2cos 2x となり、x を π ずらしても同じ式に戻ります ✓。

テストのポイント：「正で最小」と聞かれています。2π, 3π, … もすべて周期ですが、答えるのはいちばん小さい正の周期 πです。
答 (1)②π
(1)③
平行移動

y = 2cos(2x + π/3) は 2cos 2x をどれだけ平行移動したものか

次の等式を利用して、関数 y = 2cos(2x + π3) のグラフが、関数 y = 2cos 2x のグラフを x軸方向にどれだけ平行移動したものか答えよ。　2cos(2x + π3) = 2cos 2(x + π6)

y = f(x) のグラフを x軸方向に p だけ平行移動したグラフ：y = f(x − p) y = f(x + a) は 左へ a の平行移動（p = −a と考える）
2cos(2x + π3) = 2cos 2(x + π6)　（2x + π3 を 2 でくくった） これは y = 2cos 2x の x を x + π6 に置き換えたものである。 x + π6 = x − (−π6) なので、x軸方向に −π6 平行移動したもの、すなわち 左へ π6
やさしい解説：山の位置で確かめる

グラフの山（最大の点）がどこに動いたかを見ると、答えが確かめられます。

  • y = 2cos 2x の山：2x = 0 のとき、つまり x = 0
  • y = 2cos(2x + π3) の山：2x + π3 = 0 のとき、つまり x = −π6

山が x = 0 から x = −π/6 へ、左に π/6 動いています ✓。

テストのポイント：「2x + π/3 だから左へ π/3」とは答えないこと。x の係数 2 でくくって (x + π6) の形にしてから、足している数を読みます。また、「＋」なのに左へ動く（「−」なら右）点も間違えやすいので、山の位置で確かめましょう。
答 (1)③左へ π6（x軸方向に −π6）

sin x = 2cos(2x + π/3) の解の個数

グラフを利用して、方程式 sin x = 2cos(2x + π3) の解の個数を求めよ。　① 0 ≦ x ≦ π　② 0 ≦ x ≦ 2π

方程式 f(x) = g(x) の実数解 ⇔ y = f(x) と y = g(x) のグラフの共有点の x座標 解の個数 ＝ 指定された区間にある共有点の個数

やさしい解説：目印の点を先に打つ三角関数のグラフは、「山・谷・真ん中」の点を先に打ってからなめらかにつなぐと、きれいにかけます。山から山までが周期 π、山と谷はその半分（π/2）離れ、真ん中の点（y = 0）は山と谷のちょうど真ん中にあります。

STEP 2　2つのグラフを重ねて、交点を数える

y = sin x と y = 2cos(2x + π3) のグラフは、図のようになる。 ① 0 ≦ x ≦ π の範囲での共有点は ①② の 2個 ② 0 ≦ x ≦ 2π の範囲では、さらに π ≦ x ≦ 2π の範囲に ③④ の2点があるので、共有点は全部で 4個
やさしい解説：なぜ4つあるとわかる？
  • 青い波は高さ ±2 まで動き、緑の波は ±1 までしか動きません。青が緑を上から下へ、下から上へとまたぐたびに交点ができます。（x = 0 では青が y = 1、緑が y = 0 なので、青が上から始まります。）
  • 0 ≦ x ≦ π の間に、青は「緑より上 → 下 → 上」と入れかわる（①②）。
  • π ≦ x ≦ 2π の間にも、「上 → 下 → 上」と入れかわる（③④）。
  • 交点の x座標そのものを求める必要はなく、個数だけを答えます。（ただし ④ は x = 3π/2 と、下の検算のようにきれいに求まります。）
答 (2)①2個
答 (2)②4個
