毎年同じ倍率で変化するとき、その倍率を繰り返し掛けます。これは「等比数列」という数列です。例えば、毎年2倍ずつ増える人口なら、1年後は2倍、2年後は2 × 2 = 4倍になります。ここでは減少するので、r は1より小さい数（0.9付近）です。

🔵 常用対数の意味（中学の知識）

常用対数とは「10を底とする対数」のこと。log₁₀ x は「10を何乗したら x になるか」という問いです。

  • log₁₀ 10 = 1　（10¹ = 10 だから）
  • log₁₀ 100 = 2　（10² = 100 だから）
  • log₁₀ 0.1 = −1　（10⁻¹ = 0.1 だから）

3対数の性質で指数を前に出す

🔵 対数の性質：指数を前に出す

log₁₀(an) = n × log₁₀ a

つまり、指数 n は対数の前に出せます。例えば：

  • log₁₀(2³) = 3 × log₁₀ 2
  • log₁₀(r²) = 2 × log₁₀ r

🔵 対数の性質：割り算は引き算に

log₁₀(A/B) = log₁₀ A − log₁₀ B

掛け算が足し算に変わるなら、割り算は引き算に変わります。例えば：

  • log₁₀ 0.1 = log₁₀(1/10) = log₁₀ 1 − log₁₀ 10 = 0 − 1 = −1

やさしい解説：仮説検定は「裁判」に似ている

裁判では「無罪と仮定」しておいて、よほど動かぬ証拠が出ない限り無罪のままです。仮説検定も同じで、「p＝○○」をいったん正しいと仮定しておき、実際のデータがその仮定のもとでは起こりにくすぎる（珍しすぎる）場合だけ、「仮定はおかしい」と判断します。

「珍しすぎる」の基準が有意水準5％。「20回に1回あるかないかくらい珍しいことが起きたら、仮定を疑おう」という約束ごとです。

やさしい解説：なぜ両側は1.96で、片側は1.64？

有意水準5％は「全体で5％だけ珍しい部分」という意味。両側検定はプラス側とマイナス側の両方を調べたいので、5％を半分ずつ（2.5％＋2.5％）に分けます。片側検定は片方だけ調べればよいので、5％をまるごと片方に寄せます。片側だけに5％を集めた方が、境界は中心に近づく（1.64＜1.96）ので、片側検定の方が「おかしい」と判定されやすくなります。

円柱と空間ベクトル

座標空間において、A = (5, 0, 0)、B = (−75, 245, 0) とする。円柱 x² + y² = 25、0 ≦ z ≦ 10 の側面上に点 C = (a, b, c) をとり、|CA| = |CB| を満たす。点 C を通る z軸に平行な直線と xy平面との交点を D とする。 (1) (a, b) を求めよ。 (2) D = (−3, −4, 0) のとき、DA・DB を求めよ。 (3) (2) の D について、cos∠ADB を求めよ。 (4) C = (3, 4, c) のとき、|CA|² を求めよ。

(1)
距離が等しい条件

(a, b) を求める

C は円柱の側面上にあり、|CA| = |CB| を満たす。(a, b) を求めよ。

2点 P(x₁, y₁, z₁)，Q(x₂, y₂, z₂) の距離：|PQ|² = (x₂ − x₁)² + (y₂ − y₁)² + (z₂ − z₁)² 円柱の側面：a² + b² = 25　…①
|CA|² = (a − 5)² + b² + c² |CB|² = (a + 75)² + (b − 245)² + c² |CA|² = |CB|² を展開して整理すると a² − 10a + 25 + b² + c² = a² + 145a + 4925 + b² − 485b + 57625 + c² −10a + 25 = 145a − 485b + 25　（4925 + 57625 = 25） −645a = −485b　⇒　4a = 3b　…② ②より a = 3k，b = 4k とおき、①に代入：9k² + 16k² = 25k² = 25　⇒　k = ±1 よって (a, b) = (3, 4)　または　(−3, −4)
やさしい解説：なぜ2つ出てくるの？

「2点から等しい距離にある点」の集まりは、2点を結ぶ線分の垂直二等分線です。ここでは、その直線（上の図の赤い点線）と円柱の底の円が交わる2点が候補になります。直線と円は2点で交わることがあるので、答えも2つです。

(2)

cos∠ADB を求める

空間の距離

① 「傾きが同じ接線」を探す方法

楕円上の点 (x₀, y₀) における接線：x₀x3y₀y ＝ 1、傾き ＝ −x₀/(3y₀) 直線AP（傾き−1）と接線が平行になるとき、その接点が直線から一番遠い（＝距離が最大or最小になる）点
やさしい解説：なぜ「平行な接線」でよい？直線から一番遠い（または一番近い）楕円上の点では、その点での楕円の接線が、もとの直線と同じ傾きになります。イメージとしては、直線を外側にずらしていって、楕円にギリギリ触れる瞬間（接する瞬間）が、その方向で一番遠い点だからです。
−x₀/(3y₀) ＝ −1　⇒　x₀ ＝ 3y₀ 楕円の式に代入：(3y₀)²/3＋y₀²＝1　⇒　3y₀²＋y₀²＝1　⇒　y₀² ＝ 1/4　⇒　y₀ ＝ ±1/2 y₀＝1/2 のとき x₀＝3/2　／　y₀＝−1/2 のとき x₀＝−3/2

② どちらが「遠い」かを調べる

候補①(3/2, 1/2)：|3/2＋1/2−1|/√2 ＝ |1|/√2 ＝ 1/√2（近い方） 候補②(−3/2, −1/2)：|−3/2−1/2−1|/√2 ＝ |−3|/√2 ＝ 3/√2（遠い方）
ここが分かれ道：候補①はx≧0側、候補②はx＜0側です。Qにはx≧0の制限がないので、②の方が正しい候補。①だけで判断すると、元データのように答えを間違えます。

答 (2)Q ＝ (−3/2, −1/2)，△APQ の最大面積 ＝ 9/4
