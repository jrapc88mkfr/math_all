問題3
模試・円

円と接線、弧と弦で囲まれた領域

xy平面上に点 A(10, 0) で x軸に接し、点 B(6, 8) を通る円 C がある。また、B における C の接線を l とする。 (1) 円 C の方程式を求めよ。 (2) l の方程式を求めよ。 (3) 円 C の短い方の弧 AB と弦 AB で囲まれる領域（境界を含む）を D とし、点 (x, y) は D 上を動くとする。 　(i) (y − 5)/(x − 3) の最大値を求めよ。 　(ii) 0 < p < 4 を満たす定数 p に対し、(y − p)/(x − 3) の最大値と最小値の和が 2 となるとき、p の値を求めよ。

3(1)
円の方程式

中心と半径を求める

円が x軸に点 A(10, 0) で接する　⇒　中心は A を通る 垂直な直線 x = 10 の上にある。 中心を O(10, r)（r は半径、円は上側にあるとする）とおく。
B(6, 8) は円周上にあるから　OB = r (6 − 10)² + (8 − r)² = r² 16 + 64 − 16r + r² = r²　⇒　80 − 16r = 0　⇒　r = 5 よって中心は O(10, 5)、半径は 5。 (x − 10)² + (y − 5)² = 25
やさしい解説：中心の y座標は半径と同じ

円が x軸に接するとき、中心から x軸までの距離（＝中心の y座標）が半径になります。だから中心を (10, r) と置けます。

r² が両辺に出てくるので消えて、r だけの式が残ります。

テストのポイント：「接する」を見たら、中心から接線までの距離＝半径を思い出す。点を通るときは、中心との距離の2乗で式を作る。
答 (1)(x − 10)² + (y − 5)² = 25
3(2)
接線の方程式

半径と垂直な接線

円の接線は、接点を通る半径と垂直。 垂直な2直線の傾きの積 ＝ −1
半径 OB の傾き ＝ (8 − 5)/(6 − 10) = −3/4 接線 l の傾きを m とすると　(−3/4) · m = −1　⇒　m = 4/3 B(6, 8) を通るので　y − 8 = (4/3)(x − 6) 両辺に 3 をかけて　3y − 24 = 4x − 24　⇒　4x − 3y = 0
やさしい解説：なぜ傾きの積が −1？

直角に交わる2本の直線は、「右に 1 進むと上に m 上がる線」と「右に 1 進むと上に −1/m 上がる線」の関係になります。傾きどうしを掛けると −1 になるのはこのためです。

検算：B(6, 8) を代入すると　4 · 6 − 3 · 8 = 24 − 24 = 0 ✓。
テストのポイント：接線の傾きを直接求めようとせず、まず半径の傾きを計算してから、垂直条件で接線の傾きを出す。
答 (2)l：4x − 3y = 0
3(3)(i)
傾きの最大

(y − 5)/(x − 3) の最大値

領域 D 上の点 (x, y) について、(y − 5)/(x − 3) の最大値を求めよ。

P(3, 5) とおくと、(y − 5)/(x − 3) は、点 P と点 (x, y) を結ぶ直線の傾き。 よって「領域 D の中で、P から見た傾きが最大の点」を探す。

STEP 1　領域 D の端点での傾き

B(6, 8) では　(8 − 5)/(6 − 3) = 1 A(10, 0) では　(0 − 5)/(10 − 3) = −5/7

STEP 2　P から円に引いた接線の傾き

点 (x₀, y₀) と直線 ax + by + c = 0 の距離 ＝ |ax₀ + by₀ + c| / √(a² + b²)
接線を y − 5 = m(x − 3)、すなわち mx − y + 5 − 3m = 0 とおく。 中心 O(10, 5) からの距離が半径 5 に等しいので　|10m − 5 + 5 − 3m| / √(m² + 1) = 5 7|m| = 5√(m² + 1)　⇒　49m² = 25m² + 25　⇒　24m² = 25 よって　m = ±5√6/12

STEP 3　直線 PB を使って、傾きの上限を調べる

P(3, 5) と B(6, 8) を通る直線の傾きは 1 なので　y = x + 2（2点を代入して確認：5 = 3 + 2，8 = 6 + 2）
直線 y = x + 2 と円の交点：(x − 10)² + (x − 3)² = 25 x² − 13x + 42 = 0　⇒　x = 6，7　　交点は B(6, 8) と (7, 9) 直線より上にある円の部分は、B から (7, 9) までの小さな弧。この弧は、点 (7, 9)（2x + y = 23 > 20）のように、弦 AB の反対側にあるので、領域 D には入らない。 よって、D のすべての点は　y ≤ x + 2　を満たす。 D の点は x ≥ 5 なので x − 3 > 0。両辺を x − 3 で割ると　(y − 5)/(x − 3) ≤ 1
やさしい解説：接点を計算しなくても、上限が分かる

傾きが大きいほど、直線は「急な坂」になります。直線 PB より急な直線は、B より上の円の部分にしか届きません。その部分は、領域 D の外です。

だから、D の中で傾きが 1 より大きくなることはありません。傾き 1 は点 B で実現されるので、最大値は 1 と決まります。

STEP 4　結論

D のすべての点で傾きは 1 以下。 点 B(6, 8) では傾きがちょうど 1 なので、最大値は　1（(x, y) = (6, 8) のとき） （傾き 5√6/12 ≒ 1.02 の接線は、接点が D の外にあるため使えない。）
やさしい解説：接線の傾きを「答え」にしてはいけない

「接線の傾きが最大」と考えて、接線の傾き 5√6/12 を答えたくなります。でも接線は円全体に引いたものなので、接点が領域の外にあると、その傾きは領域では使えません。

そこで、まず接点が領域の中にあるかを確かめ、入っていない場合は境界（端点）の値を調べます。

テストのポイント：「傾きの最大・最小」の問題では、(1) 端点の値を計算、(2) 接線の傾きを計算、(3) 接点が領域に入っているかを確認、の3つを必ずセットで書く。
検算（数値）：領域 D の境界上の点を細かく調べると、傾きの最大は 1.0000（点B）、最小は −1.0206（≒ −5√6/12）となり、上の結論と一致 ✓。
答 (3)(i)最大値 1（(x, y) = (6, 8) のとき）　（参考：最小値 −5√6/12）
3(3)(ii)
接線と解と係数の関係

最大と最小の和が 2 となる p

0 < p < 4 を満たす定数 p に対し、(y − p)/(x − 3) の最大値と最小値の和が 2 となるとき、p の値を求めよ。

Q(3, p) から領域 D の点への直線の傾き。最大・最小は、Q から円に引いた接線の傾きで決まる。 2本の接線の傾きを m₁，m₂ とすると、解と係数の関係で和が求まる。
点 (x₀, y₀) と直線 ax + by + c = 0 の距離 ＝ |ax₀ + by₀ + c| / √(a² + b²)
直線を y − p = m(x − 3)、すなわち mx − y + p − 3m = 0 とおく。 中心 O(10, 5) からの距離が 5 なので　|7m + p − 5| = 5√(m² + 1) 両辺を2乗して　(7m + p − 5)² = 25(m² + 1) 24m² + 14(p − 5)m + (p − 5)² − 25 = 0 解と係数の関係より　m₁ + m₂ = −14(p − 5)/24 = 7(5 − p)/12 最大値と最小値の和が 2 なので　7(5 − p)/12 = 2 7(5 − p) = 24　⇒　5 − p = 24/7　⇒　p = 11/7
確認（接点が領域 D の中にあるか）：p = 11/7 のとき、接線の傾きは約 2.246 と約 −0.246。接点は約 (5.43, 7.03)（角度 約 156°）と約 (8.81, 0.14)（角度 約 256°）で、どちらも弧 AB 上にある。よって、この2つの接線の傾きが、領域 D での最大・最小になる ✓。
やさしい解説：なぜ「和」だけで答えが出る？

2次方程式の解と係数の関係により、2つの解を個別に求めなくても、和だけが分かります。最大と最小の和を条件にしているので、この方法が使えます。

テストのポイント：(ア) 接線の式を「点 + 傾き」で作る、(イ) 距離の式を2乗して、m の2次方程式にする、(ウ) 和だけを使う。さらに、接点が領域に入っているかを一言添えると、答案が完成します。
答 (3)(ii)p = 11/7
問題4
模試・指数と対数

指数関数・対数関数と不等式

関数 f(x), g(x) を　f(x) = 4x−2 − 2x−2 − 2x−1 + 2，　g(x) = loga(16a² − x²) + log1/a(6x)　により定める。ただし a は 1 でない正の定数とする。 (1) t = 2x とおくとき、f(x) を t を用いて表せ。 (2) 不等式 f(x) < 0 を解け。 (3) 0 < a < 1 のとき、不等式 g(x) > 1 を解け。 (4) f(x) < 0 を満たすすべての実数 x に対して g(x) > 1 が成り立つような a の値の範囲を求めよ。

4(1)
置きかえ

t = 2ˣ とおいて f(x) を t で表す

指数の変換：4 = 2² なので　4ˣ = (2²)ˣ = (2ˣ)²　（指数の掛け算は、底を 2 に直すと見やすい） 対数の掛け算は足し算：loga(MN) = logaM + logaN 対数の割り算は引き算：loga(M/N) = logaM − logaN 底が 1/a のとき：log1/aX = −logaX
am+n = am·an，　am−n = am/an，　(am)n = amn 4x = (2²)x = (2x)² = t² と書きかえられる。
4x−2 = 4x/4² = t²/16 2x−2 = t/4，　2x−1 = t/2 f(x) = t²/16 − t/4 − t/2 + 2 = (t² − 4t − 8t + 32)/16 = (t² − 12t + 32)/16 f(x) = (t − 4)(t − 8)/16
やさしい解説：なぜ4を2で書きかえる？

4 = 2² なので、4ˣ = (2²)ˣ = (2ˣ)² と書けます。こうすると、すべての項が 2ˣ の形になり、t だけの式になります。

テストのポイント：係数を2乗することを忘れない（4ˣ＝t²）。また、4^{x−2} = 4ˣ/16 のように、指数の引き算は割り算に直す。
検算：x = 2 のとき、f(2) = 4⁰ − 2⁰ − 2¹ + 2 = 1 − 1 − 2 + 2 = 0。t = 2² = 4 を代入すると (4 − 4)(4 − 8)/16 = 0 ✓。
答 (1)f(x) = (t − 4)(t − 8)/16
4(2)
2次不等式

f(x) < 0 を解く

(t − 4)(t − 8)/16 < 0　（16 > 0 なので） (t − 4)(t − 8) < 0　⇒　4 < t < 8 t = 2ˣ より　2² < 2ˣ < 2³ 底 2 は 1 より大きいので、指数の大小関係はそのまま保たれる。 2 < x < 3
やさしい解説：積が負になるのは？

2つの数の積が負になるのは、一方が正、もう一方が負のときです。(t − 4)(t − 8) < 0 では、t が 4 より大きく、かつ 8 より小さいときだけ。

また、2ˣ は底 2 が 1 より大きいので増加関数。だから 4 < 2ˣ < 8 を、そのまま指数の 2 < x < 3 に直せます。

テストのポイント：最後に t を x に戻すのを忘れない。また、底が 1 より大きいことを一言書く。
答 (2)2 < x < 3
4(3)
対数不等式（0 < a < 1）

g(x) > 1 を解く

STEP 1　定義域（真数は正）

16a² − x² > 0 かつ 6x > 0 よって　0 < x < 4a

STEP 2　底をそろえて1つの対数にまとめる

log1/a(6x) = −loga(6x)　（底の変換：log1/aX = −logaX） g(x) = loga(16a² − x²) − loga(6x) = loga((16a² − x²)/(6x))
割り算は引き算：logaM − logaN = loga(M/N)

STEP 3　底 a（0 < a < 1）に注意して外す

g(x) > 1 ⇔ loga((16a² − x²)/(6x)) > logaa 0 < a < 1 のとき、y = logaX は減少関数。よって　(16a² − x²)/(6x) < a
なぜ不等号の向きが逆になる？

底が 1 より小さいと、真数が大きいほど対数の値は小さくなります（例：log1/2(1/4) = 2、log1/2(1/2) = 1。真数が小さい方が対数は大きい）。だから logaX > 1 は X < a と同じ意味になります。

STEP 4　分母を払って2次不等式

x > 0 なので両辺に 6x をかけても不等号の向きは変わらない。 16a² − x² < 6ax　⇒　x² + 6ax − 16a² > 0 (x + 8a)(x − 2a) > 0　⇒　x < −8a，　x > 2a

STEP 5　定義域と合わせる

定義域 0 < x < 4a と合わせると（x < −8a は定義域外） 2a < x < 4a
テストのポイント：(ア) 真数の条件から定義域を先に出す、(イ) 底が 1 より小さいと不等号が逆、(ウ) 定義域との共通部分をとる。
答 (3)2a < x < 4a
4(4)
条件の言いかえ

「すべての x に対して」を区間の包含で考える

「f(x) < 0 を満たすすべての x で g(x) > 1」⇔「区間 (2, 3) の各点が、g(x) > 1 の解の区間に含まれる」 (2, 3) ⊂ 解の区間

(i) 0 < a < 1 の場合

(3) より g(x) > 1 の解は　2a < x < 4a。 (2, 3) ⊂ (2a, 4a) となる条件は　2a ≤ 2 かつ 4a ≥ 3 すなわち　a ≤ 1 かつ a ≥ 3/4　（0 < a < 1 と合わせて）　⇒　3/4 ≤ a < 1

(ii) a > 1 の場合（問題文の条件 a ≠ 1 を満たす残りの場合）

a > 1 のとき、y = logaX は増加関数なので　g(x) > 1 ⇔ (16a² − x²)/(6x) > a 16a² − x² > 6ax　⇒　(x + 8a)(x − 2a) < 0　⇒　−8a < x < 2a 定義域 0 < x < 4a と合わせて　0 < x < 2a (2, 3) ⊂ (0, 2a) となるには　2a ≥ 3　⇒　a ≥ 3/2
やさしい解説：底が 1 より大きいと不等号は元に戻る

a > 1 では対数は増加関数なので、logaX > 1 は X > a と同じです。(i) の 0 < a < 1 の場合とは向きが逆になるので、解の区間の形も変わります。

答え

(i) と (ii) をあわせて　3/4 ≤ a < 1　または　a ≥ 3/2
検算（数値）：a = 0.75 は ✓（区間 (1.5, 3) ⊃ (2, 3)）、a = 0.7 は ✗、a = 1.4 は ✗（区間 (0, 2.8) は 3 まで届かない）、a = 1.5 は ✓（区間 (0, 3) ⊃ (2, 3)）。範囲は数値計算でも一致 ✓。
テストのポイント：「すべての x に対して」は、区間の包含（端点の比較）で考える。また、a の範囲は問題文の条件（0 < a < 1 か、a > 1 か）を必ず確認する。今回は問題文に 0 < a < 1 の指定がないので、両方の場合を書く。
答 (4)3/4 ≤ a < 1　または　a ≥ 3/2
