問題
数学Ⅱ 第3問

三次関数の接線・平行移動 ／ 偶関数と定積分

〔1〕　関数 f(x) = x3 − 3x2 + x のグラフを C とする。 (1) f″(x) を求めよ。 (2) C 上の点 (−1, f(−1)) における接線を ℓ とするとき、ℓ の方程式を求めよ。 (3) y = f′(x) のグラフの対称軸を求め、ℓ と平行な別の接線の接点の x座標を求めよ。 (4) C を y軸方向に d だけ平行移動した曲線 C′ が ℓ と接するとき、d を求めよ。ただし d は 0 でない実数とする。

〔2〕　a, b を正の定数とし、g(x) = ax2 + b とする。g(x) は常に正で、グラフは y軸に関して対称である。さらに h(t) = ∫t−1g(x)dx と定め、h(t) の増減や定積分の等式を調べる。 （元の問題文・空欄の一部が確認できないため、上の条件から言えることを扱います。）

〔1〕(1) 微分を2回 → (2) 接点と傾き → 接線の式 → (3) 軸と f′(x) = 10 → (4) 接点で「y座標も傾きも等しい」 〔2〕(1) 偶関数（y軸対称）→ (2) h′(t) = g(t) → 等式は「左の面積 ＝ 右の面積」
この問題の合言葉：「接線は点＋傾き、傾きは微分」「平行は傾きが同じ」「接するは同じ点で傾きも同じ」「偶関数は左右対称で、面積も左右で同じ」。
〔1〕
(1)
二階導関数

f″(x) を求める

関数 f(x) = x3 − 3x2 + x について、f″(x) を求めよ。

(xn)′ = n·xn−1　（定数を微分すると 0） 二階導関数：f″(x) = (f′(x))′　（f′(x) をもう一度微分する）
f(x) = x3 − 3x2 + x f′(x) = 3x2 − 6x + 1 f″(x) = 6x − 6
やさしい解説：二階導関数とは

f′(x) は「グラフの接線の傾き」を表す式でした。f″(x) は、その f′(x) をもう一度微分したもので、「傾きがどう変わっていくか」（グラフの曲がり方）を表します。

各項は、3x2 → 6x、−6x → −6、1 → 0（定数は消える）と微分していきます。

テストのポイント：1回目の微分で出てくる定数 1 は、2回目の微分で消えることに注意。また、微分は「指数を前に出して、指数を 1 下げる」だけです。
答 〔1〕(1)f″(x) = 6x − 6
〔1〕
(2)
接線

点 (−1, f(−1)) における接線 ℓ

C 上の点 (−1, f(−1)) における接線を ℓ とするとき、ℓ の方程式を求めよ。

点 (a, f(a)) における接線：y − f(a) = f′(a)(x − a) 必要なもの：接点の座標 (a, f(a)) と 傾き f′(a)
① 接点：f(−1) = (−1)3 − 3(−1)2 + (−1) = −1 − 3 − 1 = −5　⇒　接点は (−1, −5) ② 傾き：f′(−1) = 3(−1)2 − 6(−1) + 1 = 3 + 6 + 1 = 10 ③ 接線：y − (−5) = 10{x − (−1)}　⇒　y + 5 = 10(x + 1)　⇒　y = 10x + 5
やさしい解説：接線は「点」と「傾き」で決まる

直線は「通る点」と「傾き」が分かれば決まります（中学の一次関数と同じ）。通る点は接点、傾きは接点での微分係数 f′(a) です。

テストのポイント：マイナスの計算に注意：(−1)2 = 1、(−1)3 = −1、−6 × (−1) = +6。接点の y座標 f(−1) を、f′ と取り違えないこと。
検算：ℓ と C の式を連立すると f(x) − (10x + 5) = x3 − 3x2 − 9x − 5 = (x + 1)2(x − 5)。x = −1 が重解（2乗の因数）なので、ℓ は x = −1 で C に接しています ✓。
答 〔1〕(2)ℓ：y = 10x + 5

(3)
軸・平行な接線

f′(x) のグラフの対称軸と、ℓ に平行な別の接線

y = f′(x) のグラフの対称軸を求め、ℓ と平行な別の接線の接点の x座標を求めよ。

2次関数 y = ax2 + bx + c の軸：x = −b2a 平行な接線 ⇔ 傾きが等しい　⇒　接点の x座標は f′(x) = (傾き) の解
f′(x) = 3x2 − 6x + 1 の軸は　x = −−62 × 3 = 1　（グラフは直線 x = 1 に関して対称） ℓ の傾きは 10。ℓ と平行な接線の傾きも 10 なので　f′(x) = 10 3x2 − 6x + 1 = 10　⇒　3x2 − 6x − 9 = 0　⇒　x2 − 2x − 3 = 0　⇒　(x − 3)(x + 1) = 0 x = 3, −1　（x = −1 は ℓ の接点）　⇒　別の接点の x座標は 3
やさしい解説

平行な直線は傾きが同じです。傾きは微分 f′(x) で分かるので、「f′(x) = 10 となる x」が、傾き 10 の接線の接点になります。解は 2つ出て、1つはもとの接点 x = −1、もう1つが求める x = 3 です。

確かめ：2つの解 −1 と 3 は軸 x = 1 から同じ距離（2）だけ離れています。−1 + 32 = 1 ✓（2解の真ん中が軸になります）。

テストのポイント：「別の接点」と聞かれているので、x = −1 は答えではありません。f′(x) = 10 を解いて出た 2つのうち、すでに分かっている方を除きます。
検算：x = 3 での接線は、f(3) = 27 − 27 + 3 = 3、傾き 10 なので y − 3 = 10(x − 3)、つまり y = 10x − 27（右の図の緑の線）。ℓ と傾きが同じで平行です ✓。
答 〔1〕(3)対称軸 x = 1，別の接点の x座標 x = 3

(4)
平行移動・接する条件

y軸方向に d だけ平行移動した曲線 C′ が ℓ に接する

C を y軸方向に d だけ平行移動した曲線 C′ が ℓ と接するとき、d を求めよ。ただし d は 0 でない実数とする。

y軸方向に d だけ平行移動：y = f(x) + d 曲線と直線が x = p で接する ⇔ p で「y座標も傾きも等しい」
C′：y = x3 − 3x2 + x + d。C′ の傾きは (f(x) + d)′ = f′(x)　（d は微分すると消える） ℓ（傾き 10）と接する点では C′ の傾きも 10 なので　f′(x) = 10　⇒　x = −1, 3　（(3) と同じ） (i) x = −1 のとき：C′ の y座標 f(−1) + d = −5 + d、ℓ の y座標 10(−1) + 5 = −5　⇒　d = 0　（d ≠ 0 に反するので不適） (ii) x = 3 のとき：C′ の y座標 f(3) + d = 3 + d、ℓ の y座標 10·3 + 5 = 35　⇒　3 + d = 35　⇒　d = 32
やさしい解説：なぜ x = 3 を使うの？
  • C を上下にずらしても、各 x での傾きは変わりません（形を保ったまま動かすだけ）。だから、傾き 10 の点は x = −1 と x = 3 のまま。
  • x = −1 を使うと d = 0（動かさないこと）になり、問題の「d は 0 でない」に反します。だから x = 3。
  • x = 3 で C′ の高さ（3 + d）が ℓ の高さ（35）にちょうど重なるように、C を 32 だけ上へ動かします。
検算（重解を使う方法）：C′ と ℓ の式を連立すると x3 − 3x2 + x + d = 10x + 5　⇒　x3 − 3x2 − 9x + (d − 5) = 0。接する ⇔ この方程式が重解をもつ。
d = 32 のとき　x3 − 3x2 − 9x + 27 = (x − 3)2(x + 3)：x = 3 が重解（接点）✓、x = −3 は別の交点です。また f′(3) = 27 − 18 + 1 = 10 で、傾きも ℓ と一致しています ✓。
テストのポイント：「接する」は「y座標が等しい」だけでなく「傾きも等しい」ことまで使います。傾きの条件で接点の候補（x = −1, 3）をしぼり、y座標の条件で d を決める、という順番です。
答 〔1〕(4)d = 32

(1)
偶関数

g(x) = ax² + b は偶関数：対称な区間の積分は等しい

a, b を正の定数とし、g(x) = ax2 + b とする。g(x) の対称性と、対称な区間の定積分について調べよ。

偶関数 ⇔ g(−x) = g(x)　（グラフが y軸に関して対称） 偶関数の定積分：∫−a−bg(x)dx = ∫bag(x)dx　　∫b−bg(x)dx = 2∫b0g(x)dx
g(−x) = a(−x)2 + b = ax2 + b = g(x)　⇒　g は偶関数（グラフは y軸対称） したがって、原点をはさんで対称な区間の積分値は等しい。たとえば　∫−c−5g(x)dx = ∫5cg(x)dx
やさしい解説：y軸で折ると重なる

偶関数のグラフは、y軸で折り返すとぴったり重なります。だから、y軸をはさんで左右対称な 2つの部分は同じ形・同じ面積になります（下の図の A と B）。

例：g(x) = x2 + 1（a = b = 1）で、∫−1/2−3/2g(x)dx と ∫3/21/2g(x)dx はどちらも 2512 です。

テストのポイント：積分の上端と下端の符号が入れかわるのがコツです（−5 〜 −c と c 〜 5）。なお、この等式は g が偶関数であれば c の値に関係なく成り立つので、この式だけから c の値は決まりません。空欄の値は元の問題文の条件で決めます。

(2)i・ii
積分で定義された関数

h(t) の増減と、左右の面積が等しくなる t

h(t) = ∫t−1g(x)dx について、(i) h(t) の増減を調べよ。(ii) ∫t−1g(x)dx = ∫1tg(x)dx（−1 ≦ t ≦ 0）となる t を求めよ。

(i) h(t) の増減

h(t) = ∫tag(x)dx ⇒ h′(t) = g(t)　（上端を t にした積分を t で微分すると、中身の関数に t を入れたもの）
h′(t) = g(t) = at2 + b a, b ＞ 0 より at2 ≧ 0 なので　at2 + b ≧ b ＞ 0　⇒　すべての実数 t で h′(t) ＞ 0 よって h(t) は、実数全体で単調に増加する。
やさしい解説：面積がどんどん増えるh(t) は「−1 から t までの、g(x) のグラフの下の面積」です。t を右へ動かすほど、面積が足されていきます。g(x) は常に正なので、足されるのは正の面積ばかり。だから h(t) は増える一方です（h′(t) ＞ 0 ⇔ 増加）。
答 (2)(i)どの t でも h′(t) ＞ 0 なので、h(t) は常に増加する

(ii) 左右の面積が等しくなる t

やさしい解説：式を絵で読む∫t−1g(x)dx は、−1 から t までの左の面積。∫1tg(x)dx は、t から 1 までの右の面積。つまり「−1 から 1 までを、t で2つに分けたとき、左と右の面積が等しい」という式です。
∫t−1g(x)dx = ∫0−1g(x)dx + ∫t0g(x)dx ∫1tg(x)dx = ∫0tg(x)dx + ∫10g(x)dx g は偶関数なので ∫0−1g(x)dx = ∫10g(x)dx。また ∫0tg(x)dx = −∫t0g(x)dx よって等式は　∫t0g(x)dx = −∫t0g(x)dx　⇒　2∫t0g(x)dx = 0　⇒　∫t0g(x)dx = 0 g(x) ＞ 0 なので、t ＜ 0 のとき ∫t0g(x)dx = −∫0tg(x)dx ＜ 0 で 0 にならない。よって t = 0
やさしい解説：図で確かめる左の図（t ＝ −0.5）では、左（青）の面積が右（黄）よりずっと小さく、等しくありません。右の図（t ＝ 0）のときだけ、y軸で左右にちょうど分かれて左 ＝ 右 になります。偶関数は左右対称なので、真ん中（t = 0）が「面積を2等分する位置」です。
検算（直接計算）：∫t−1g(x)dx − ∫1tg(x)dx = 2t3(at2 + 3b)。これが 0 になるのは t = 0 のとき、または at2 + 3b = 0 のとき。a, b ＞ 0 なので at2 + 3b ≧ 3b ＞ 0 で後者は起こりません。よって t = 0 だけ ✓。
テストのポイント：区間を 0 で分けるのが決め手です。偶関数の性質（∫0−1 = ∫10）と、向きを入れかえると符号が変わる性質（∫0tg = −∫t0g）の2つを使います。
答 (2)(ii)t = 0

大小・h(0) の値

h(t) と h(0) の大小、および h(0) の値

(iii) h(t) と h(0) の大小

h(t) が増加関数 ⇒ t1 ＜ t2 ならば h(t1) ＜ h(t2)
(i) より h′(t) ＞ 0 なので h(t) は単調に増加する。よって −1 ≦ t ＜ 0 のとき　h(t) ＜ h(0)　（t = 0 のときは h(t) = h(0)）
やさしい解説増える一方の関数では、右にいくほど値が大きい。t は 0 より左（小さい）なので、h(t) は h(0) より小さくなります。
答 (2)(iii)−1 ≦ t ＜ 0 で h(t) ＜ h(0)

(iv) h(0) の値と、a・b との関係

∫qp(ax2 + b)dx = [ a3x3 + bx ]qp
h(0) = ∫0−1(ax2 + b)dx = [ a3x3 + bx ]0−1 = 0 − ( −a3 − b ) = a3 + b また h(−1) = ∫−1−1g(x)dx = 0。h は増加するので、−1 ≦ t ≦ 0 では t = −1 で最小、t = 0 で最大。
やさしい解説：h(t) の式を使って確かめる一般の t で計算すると h(t) = a(t3 + 1)3 + b(t + 1)。t = −1 を入れると 0、t = 0 を入れると a3 + b ✓。
テストのポイント（元の資料からの整理）：問題文から確実に言えるのは h(0) = a/3 + b までです。もし問題に「h(0) = ○○」のような条件があれば a3 + b = ○○ という式になります。ただし式が1本だけでは a と b の値は決まりません。もう1つの条件（元の問題文にある「最小値が…」など）が必要です。
答 (2)(iv)h(0) = a3 + b，　h(−1) = 0
