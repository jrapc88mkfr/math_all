問題
Y3 数学　問題の確認

接線 → 垂線 → 面積 → 平行移動した放物線

f(x) = 12x2 − 32x + 3 のグラフを C1 とする。点 P(2, 2) における接線を ℓ とする。 (1) ℓ の方程式と、ℓ と x 軸との交点 Q を求めよ。 (2) C1 と y 軸、線分 PR で囲まれた部分の面積を求めよ。ただし R は、P を通り ℓ に垂直な直線と y 軸との交点とする。 (3) C1 を平行移動した放物線で、PR の中点と QR の中点を通るものを C2 とする。△PQR の内部で、C1 の下側かつ C2 の下側にある部分の面積 S を求めよ。

(1)　微分 → 接線の傾き → ℓ の式 → 点 Q (2)　垂直（傾きの積が −1）→ 点 R → 「上 − 下」を積分 (3)　中点 M, N → C2 の式 → 三角形 − 余分な2つの部分
やさしい解説：前の答えを次に使うこの問題は、(1)で求めた ℓ と P を(2)で、(2)で求めた R と面積を(3)で、と答えがつながっています。(1)を間違えると(2)(3)も全部ずれるので、(1)は特にていねいに。
(1)
接線

接線 ℓ の方程式と、x軸との交点 Q

① 微分して、点 P での接線の傾きを求める

(xn)′ = n·xn−1　　（定数を微分すると 0）
f(x) = 12x2 − 32x + 3 f′(x) = 12·2x − 32 = x − 32 f′(2) = 2 − 32 = 12　← 点 P での接線の傾き
やさしい解説：微分すると接線の傾きがわかる

微分すると「グラフの各点での接線の傾き」が出ます。12x2 は 2 を前に出して指数を 1 つ下げて 12·2x = x、−32x は x が消えて係数だけ残り −32、定数 3 は 0 になります。

傾き 12 は「右へ 2 進むと、上へ 1 上がる」という傾きです（下の図の点線の三角形）。

② 点 P を通る直線の式を作る

傾き m で点 (a, b) を通る直線：y − b = m(x − a)
m = 12，(a, b) = (2, 2)　⇒　y − 2 = 12(x − 2) y = 12x − 1 + 2　⇒　ℓ：y = 12x + 1

③ x軸との交点 Q

0 = 12x + 1　⇒　12x = −1　⇒　x = −2　⇒　Q(−2, 0)
テストのポイント：x軸上の点では y = 0。交点の答えは x座標と y座標の両方を書いて Q(−2, 0) とします（「x = −2」だけでは点の座標になっていません）。
検算：ℓ に P(2, 2) を代入 → 12·2 + 1 = 2 ✓　Q(−2, 0) を代入 → 12·(−2) + 1 = 0 ✓
答 (1)ℓ：y = 12x + 1，　Q(−2, 0)
(2)
垂線・面積

垂直な直線 PR と、囲まれた部分の面積

① 点 R を求める（ℓ に垂直な直線 PR）

2直線が垂直 ⇔ 傾きの積が −1：m1 · m2 = −1
やさしい解説：垂直な直線の傾き垂直な直線の傾きは、もとの傾きの「逆数にして、符号を反対」にします。12 → 逆数は 2 → 符号を変えて −2。確かめると 12 × (−2) = −1 ✓。
PR の傾き = −2　⇒　y − 2 = −2(x − 2)　⇒　y = −2x + 6 R は y 軸上（x = 0）　⇒　y = 6　⇒　R(0, 6)

② 面積の式を立てる

S = ∫ba{(上の式) − (下の式)}dx　（a ≦ x ≦ b で、上の式 ≧ 下の式）
やさしい解説：どちらが上？

囲まれた部分は x = 0（y軸）から x = 2（点 P の x座標）までです。この間で、上が PR、下が C1 です。

確かめ：x = 1 を代入すると、PR は y = −2 + 6 = 4、C1 は 12 − 32 + 3 = 2。4 ＞ 2 なので PR の方が上です。

(−2x + 6) − (12x2 − 32x + 3) = −12x2 − 2x + 32x + 6 − 3 = −12x2 − 12x + 3
テストのポイント：かっこの前のマイナスは、かっこの中の全部の項にかけます。−(−32x) は +32x になります。ここを写し間違えるミスが多いので注意。

③ 積分する

∫ xn dx = xn+1n+1 + C　　（定積分では C は不要）
S = ∫20(−12x2 − 12x + 3)dx = [ −x36 − x24 + 3x ]20 = −86 − 44 + 6 = −43 − 1 + 6 = 113
テストのポイント：最後は「x = 2 の値 − x = 0 の値」。今回は x = 0 を入れると全部 0 になるので、引き算が省けて見えるだけです。面積は必ず正の数。負になったら上と下を逆にしていないか確認しましょう。
答 (2)113
(3)
平行移動・面積

平行移動した放物線 C2 と、「三角形 − 2つの部分」で求める面積

STEP 1　2つの中点 M, N を求める

2点 (x1, y1)，(x2, y2) の中点：( x1 + x22 , y1 + y22 )
PR の中点 M：P(2, 2)，R(0, 6)　⇒　M( 2 + 02 , 2 + 62 ) = M(1, 4) QR の中点 N：Q(−2, 0)，R(0, 6)　⇒　N( −2 + 02 , 0 + 62 ) = N(−1, 3)
やさしい解説中点は、x座標どうし・y座標どうしをそれぞれ足して 2 で割る（平均をとる）だけです。C2 はこの M と N の両方を通ります。

STEP 2　C2 の式を求める

平行移動しても放物線の形は変わらない　⇒　x2 の係数は C1 と同じ 12 C2：y = 12x2 + ax + b　（a, b を M, N の座標から決める）
M(1, 4) を代入：4 = 12 + a + b　…① N(−1, 3) を代入：3 = 12 − a + b　…② ① − ②：1 = 2a　⇒　a = 12 ② に代入：3 = 12 − 12 + b　⇒　b = 3 C2：y = 12x2 + 12x + 3
検算：x = 1 を代入 → 12 + 12 + 3 = 4 ✓（M）　x = −1 を代入 → 12 − 12 + 3 = 3 ✓（N）
やさしい解説：なぜ未知数は 2 つ？形は同じで位置だけがずれるので、決めるのは「右へいくつ・上へいくつ」の 2 つ（a と b）。M と N の 2 点を通る条件で、式が 2 本できて a, b が決まります。
参考：C2 は C1 を x 方向に −2、y 方向に +1 だけ平行移動した放物線です。

STEP 3　C1 と C2 の上下を比べる

C1 − C2 = (12x2 − 32x + 3) − (12x2 + 12x + 3) = −2x x ＜ 0 のとき −2x ＞ 0　⇒　C1 の方が上（C2 が下） x = 0 のとき 差は 0　⇒　2つの放物線は点 (0, 3) で交わる x ＞ 0 のとき −2x ＜ 0　⇒　C2 の方が上（C1 が下）
やさしい解説：「C₁の下側かつC₂の下側」とは？2つの放物線のうち低い方より下、という意味です。x ＜ 0 では C2 が低く、x ＞ 0 では C1 が低い。低い方が入れかわるのは x = 0（y軸）です。

STEP 4　方針：三角形から「はみ出す 2 つの部分」を引く

S = △PQR − A − B A：x ≧ 0 で、C1 より上（PR より下）にある部分　⇒　(2) の部分と同じ B：−1 ≦ x ≦ 0 で、C2 より上（QR より下）にある部分
やさしい解説：なぜ引き算にするの？

三角形の中で「下側」を直接積分すると、上の境界が場所によって変わって式が 3 つになります。それより、三角形全体から、上にはみ出す部分を取り除く方が考えやすくなります。

取り除く A と B は、どちらも「放物線と直線で囲まれた部分」です（A は C1 と PR、B は C2 と QR）。さらにどちらも、2つの放物線が交わる点 (0, 3) から R(0, 6) までの y軸上の線分でも区切られます。

x が −2 〜 −1 の間は、三角形がまるごと C2 の下に入っているので、取り除くものはありません。

STEP 5　△PQR の面積

PQ は ℓ 上にあり、(2) で ℓ ⊥ PR とした　⇒　∠P = 90° PQ = √((−2 − 2)2 + (0 − 2)2) = √20 = 2√5 PR = √((0 − 2)2 + (6 − 2)2) = √20 = 2√5 △PQR = 12 × PQ × PR = 12 × 2√5 × 2√5 = 10
やさしい解説(2) で ℓ と PR を垂直にしたので、△PQR は P が直角の直角三角形です。2点間の距離は三平方の定理（横の差と縦の差を 2 乗して足し、ルートをとる）で出せます。
検算：座標から面積を出す公式 12|ad − bc|（PQ ＝ (−4, −2)，PR ＝ (−2, 4) とする）
12|(−4)(4) − (−2)(−2)| = 12|−16 − 4| = 12 × 20 = 10 ✓

STEP 6　A の面積（(2) の答えをそのまま使う）

A = ∫20{(−2x + 6) − C1}dx = (2) の面積 = 113
やさしい解説A は「C1 と y軸、線分 PR で囲まれた部分」で、(2) で求めた部分そのものです。(2) の答えがそのまま使えます。

STEP 7　B の面積

QR の傾き = 6 − 00 − (−2) = 3　⇒　y − 0 = 3(x + 2)　⇒　y = 3x + 6
(3x + 6) − (12x2 + 12x + 3) = −12x2 + 52x + 3 = −12(x + 1)(x − 6)
やさしい解説B は、上が QR、下が C2 です。x = −1 のとき差は 0（QR と C2 が点 N で交わる）。−1 ＜ x ＜ 6 では差が正（QR が上）なので、B は x = −1 から x = 0 までです。
B = ∫0−1(−12x2 + 52x + 3)dx = [ −x36 + 5x24 + 3x ]0−1 = 0 − ( 16 + 54 − 3 ) = −( 212 + 1512 − 3612 ) = 1912
テストのポイント：積分区間の左はしは x = −1（QR と C2 の交点 N）、右はしは x = 0（C1 と C2 の交点で、低い方が入れかわる位置）。左はしを −2 にしてしまうと、−2 〜 −1 では C2 が QR より上にあって引き算の向きが逆になり、面積が合いません。

STEP 8　引き算して答えを出す

S = △PQR − A − B = 10 − 113 − 1912 = 12012 − 4412 − 1912 = 5712 = 194
答 (3)C2：y = 12x2 + 12x + 3，　S = 194
検算（別の方法）：下の辺 PQ（ℓ）から、上の境界が変わる x = −1, 0 で 3 つに分けて、直接足します。
S1 = ∫−1−2{(3x + 6) − (12x + 1)}dx = ∫−1−2(52x + 5)dx = 54
S2 = ∫0−1{C2 − ℓ}dx = ∫0−1(12x2 + 2)dx = 136
S3 = ∫20{C1 − ℓ}dx = ∫20(12x2 − 2x + 2)dx = 43
S = 54 + 136 + 43 = 1512 + 2612 + 1612 = 5712 = 194 ✓ 同じ答えになりました。
テストでの書き方：「S = △PQR − A − B」の形にすると式が短く、検算もしやすくなります。ただし A, B がどの部分かを必ず示すこと（例：「C1 より上の部分を A、C2 より上の部分を B とする」）。
