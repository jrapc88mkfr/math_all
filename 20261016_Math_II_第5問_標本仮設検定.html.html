問題
第5問

標本平均・分散・仮説検定

(1)　A地域の受験生1000人の得点は、平均 51点、標準偏差 11点である。この中から無作為に 25人を選び、その得点の平均を X とする。また、B地域の受験生の得点は、平均 51点、標準偏差 33点である。B地域から無作為に n 人を選び、その得点の平均を Y とする。ただし母集団は十分大きいものとする。 ① E(X) と σ(X) を求めよ。 ② σ(X) = σ(Y) となるときの n を求めよ。

(2)　A地域1000人と、B地域 k 人を合わせた全体の標準偏差は 22点である。A地域・B地域の平均点はともに 51点である。B地域の受験生数 k を求めよ。

(3)　C地域の母平均を m とする。標本の大きさは 100、母標準偏差は 11点である。無作為抽出した 100人の平均点は 53.2点であった。有意水準 5% で「C地域の平均点は 51点より高い」といえるかを検定せよ。

(1)　標本平均の期待値は母平均、標準偏差は 母標準偏差 ÷ √n → 2つの標準偏差を等しくして n を求める (2)　全体の分散を、人数で重みをつけて計算 → 標準偏差 22 から分散 484 を使う (3)　仮説を立てる → 標準化して z を求める → p値と有意水準を比べる
この問題の合言葉：「平均を集めると、ばらつきは ÷ √n で小さくなる」「地域を合わせるときは、分散を人数で重みづけする」「p値が有意水準より小さければ、仮説を棄却する」。
(1)①
標本平均の期待値・標準偏差

E(X) と σ(X)

A地域の母平均 51、母標準偏差 11、標本の大きさ 25 のとき、標本平均 X の期待値 E(X) と標準偏差 σ(X) を求めよ。

母平均 μ、母標準偏差 σ、標本の大きさ n の標本平均 X̄ について E(X̄) = μ　　σ(X̄) = σ / √n
E(X) = 51 σ(X) = 11√25 = 115 = 2.2　（点）
やさしい解説：なぜ平均は狭くなる？

1人の得点は、高い人も低い人もいて大きくばらつきます。でも25人の平均をとると、高い人と低い人が打ち消し合うので、平均の値は 51 の近くに集まります。人数を増やすほど、この打ち消しが効いてばらつきが小さくなります。その割合が √n で、σ を √n で割るという公式になります。

今回は √25 = 5 なので、11 ÷ 5 = 2.2 です。

テストのポイント：期待値は変わらない（51のまま）、標準偏差は割る（÷ √n）。「期待値も割る」「標準偏差は √n を掛ける」と逆にしないこと。
答 (1)①E(X) = 51，σ(X) = 11/5 = 2.2 点
(1)②
標準偏差を等しくする

σ(X) = σ(Y) となる n

B地域の母標準偏差は 33、標本の大きさは n である。σ(X) = σ(Y) となるときの n を求めよ。

σ(Y) = 33√n　　σ(X) = 115 より 115 = 33√n 両辺を 11 で割って　15 = 3√n　⇒　√n = 15　⇒　n = 225
やさしい解説：ばらつきを「同じ」にするには

B地域の個人の標準偏差は 33 で、A地域の 11 の3倍です。平均のばらつきを 2.2 に揃えるには、「3倍のばらつきを、√n の割り算で打ち消す」必要があります。そのため √n = 3 × 5 = 15、つまり人数は 15² = 225 人です。

検算：33 ÷ √225 = 33 ÷ 15 = 2.2 ✓（A地域の σ(X) と一致）。
テストのポイント：「標準偏差が等しい」の式を作るときに、標準偏差どうしを等しくします（分散 121 と 1089 を比べて n を出すのは、同じ答えになりますが、式の形がずれやすいので注意）。
答 (1)②n = 225 人
(2)
2つの地域をまとめた分散

全体の標準偏差 22 から、B地域の人数 k を求める

A地域1000人と、B地域 k 人を合わせた全体の標準偏差は 22点である。A・B 両地域の平均は、ともに 51点である。k を求めよ。

全体の平均 ＝ 各地域の平均を人数で重みづけした平均（今回は両方 51 なので、全体の平均も 51） 全体の分散 ＝ （A の人数 × A の分散 ＋ B の人数 × B の分散）／（A の人数 ＋ B の人数） 分散 ＝ 標準偏差2 222 = 484
A の分散 11² = 121、B の分散 33² = 1089 より 1000×121 + k×10891000 + k = 484 両辺に (1000 + k) をかけて　121000 + 1089k = 484000 + 484k 605k = 363000　⇒　k = 600
やさしい解説：なぜ「分散」を人数で重みづけするの？

全体のばらつきは、「1人ひとりが平均からどれだけ離れているか（その2乗）」を全員分平均したものです。A地域は人数が多いので、そのばらつき 121 を 1000 人分、B地域は k 人分足して、全員の数で割ります。これが上の式です。

また、標準偏差は足したり平均したりしてはいけません。たとえば単純に「11 と 33 の平均」をとると 22 になりますが、それは人数を考えていないので、正しくありません（人数を考えると答えは 600 人になります）。

検算：k = 600 を入れると　(121000 + 653400) / 1600 = 774400 / 1600 = 484　→　√484 = 22 ✓。
テストのポイント：①標準偏差 22 は 22² = 484 に直してから式に入れる。②分子の「k × 33²」の 33² を忘れない（33 のままにすると大きくずれる）。③「平均」は両方 51 なので、分散の式で平均の項は消えて、人数の重みだけが残る。
答 (2)k = 600 人
(3)
仮説検定（母平均）

C地域の平均は 51 より高いといえるか（有意水準 5%）

C地域の母平均を m とする。標本の大きさ 100、母標準偏差 11点。無作為抽出した 100人の平均点は 53.2点であった。有意水準 5% で「C地域の平均点は 51点より高い」といえるかを検定せよ。

① 仮説を立てる

帰無仮説　H₀ ： m = 51（「変わらない」と仮定する） 対立仮説　H₁ ： m ＞ 51（「高い」といいたい） 対立仮説が「＞」なので、右側検定を行う。
やさしい解説：裁判と同じしくみ

裁判では「無罪」を仮定しておき、証拠が十分強いときだけ有罪とします。仮説検定も同じで、帰無仮説 H₀（＝ 今の仮定）をまず正しいとしておき、観測したデータがそれでは起こりにくすぎるとき、H₀ を捨てて H₁ を採用します。

② 帰無仮説のもとでの標本平均の分布

H₀ のもとで m = 51 なので、標本平均 X̄ の期待値は 51。標準偏差は σ(X̄) = 11√100 = 1110 = 1.1 標本が 100人と大きいので、X̄ は近似的に正規分布 N(51, 1.1²) に従う。

③ 検定統計量 z を求める

z = ( X̄ − 51 ) / ( 11 / √100 ) z = ( 53.2 − 51 ) / 1.1 = 2.2 / 1.1 = 2

④ p値を求める

p値 ＝ P(Z ≧ 2) ≒ 0.0228　（Z は標準正規分布に従う）
やさしい解説：p値とは何か

p値は「もし H₀ が正しいとしたら、今回以上に極端な結果が出る確率」です。今回は 53.2 点以上になる確率で、約 2.3%（100人中2〜3回程度）しか起こりません。

注意：p値は「H₀ が正しい確率」ではありません。

⑤ 有意水準 5% で判定する

p値 0.0228 ＜ 有意水準 0.05　⇒　帰無仮説 H₀ を棄却する （右側検定の境界は z ＝ 1.64。z = 2 は境界より外側なので、棄却される）
結論有意水準 5% で、C地域の平均点は 51点より高いといえる。
注意：「平均が高いと証明した」のではありません。「51 だとすると、この結果はめったに起こらないので、51 とは考えにくい」という判断です。また、有意水準 5% で判断しているので、5% の確率で間違える可能性はあります。
テストのポイント：①対立仮説の向き（＞、＜、≠）で、右側・左側・両側を決める。②p値と有意水準を比べ、p値が小さければ棄却。③結論は「51 より高いといえる」のように、有意水準を明記して書く。
答 (3)z = 2，p値 ≒ 0.0228 ＜ 0.05 より H₀ を棄却。有意水準 5% で「高いといえる」

FINAL CHECK

ここだけ確認

超重要・一言で覚える：「標本平均は 期待値 μ、標準偏差 σ ÷ √n」「地域をまとめるときは 分散を人数で重みづけ」「検定は z を出して p値と有意水準を比べる」。
  1. (1)①：E(X) = 51、σ(X) = 11 ÷ √25 = 2.2。
  2. (1)②：11/5 = 33/√n → √n = 15 → n = 225。
  3. (2)：全体の分散 484 = (1000·121 + k·1089)/(1000 + k) → k = 600。標準偏差は足さない。
  4. (3)：H₀：m = 51、H₁：m ＞ 51（右側）。σ(X̄) = 1.1、z = 2、p ≒ 0.0228 ＜ 0.05 → 棄却、「高いといえる」。
