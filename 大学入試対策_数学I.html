まず覚える：相加相乗平均

a ＞ 0，b ＞ 0 のとき　a ＋ b2 ≧ √(ab)　（等号は a ＝ b のとき） とくに b ＝ 1/a のとき：　a ＋ 1/a ≧ 2　（等号は a ＝ 1）
やさしい解説：2種類の「平均」
  • 相加平均＝ふつうの平均。足して2で割る（a＋b）÷2。
  • 相乗平均＝かけ算してルートをとる √(ab)。

例：a＝1，b＝9 のとき、相加平均は (1＋9)÷2＝5、相乗平均は √9＝3。いつも 相加 ≧ 相乗 になります。

なぜ成り立つ？　2乗は 0 以上なので (√a−√b)² ≧ 0。展開すると a−2√(ab)＋b ≧ 0、移項して a＋b ≧ 2√(ab)。等号は √a＝√b、つまり a＝b のとき。

a + 1/a ≧ 2 の場合：a×(1/a)＝1 なので、√1＝1。両辺を2倍して a＋1/a ≧ 2。

⚠ 使える条件：かならず a ＞ 0。たとえば a＝−1 だと a＋1/a＝−2 で、2以上になりません。
2x＋2−x の問題では、まず a＝2x ＞ 0 とおく（2の何乗も、かならず正の数）のがカギ。

次数を下げて、式を短くする

x ＝ 1 − √5，x2 − 2x − y ＝ 0，y ＝ 4 のとき、x4 − 5x3 − 14x ＋ 3 の値を求める。

やさしい解説：4乗を直接計算しない

(1−√5)⁴ をそのまま展開するとたいへん。そこで「x がみたす2次方程式」を使って、x³, x⁴ を 「x の1次式」に書き換えます。これを次数下げといいます。

① x がみたす2次方程式を作る

y＝4 を代入：x2 − 2x − 4 ＝ 0 x2 ＝ 2x ＋ 4　← これが「次数下げの道具」

確認：x−1＝−√5 の両辺を2乗すると x²−2x＋1＝5、つまり x²−2x−4＝0 になります。

② x³ と x⁴ を1次式にする

x3 ＝ x·x2 ＝ x(2x＋4) ＝ 2x2＋4x ＝ 2(2x＋4)＋4x ＝ 8x ＋ 8 x4 ＝ x·x3 ＝ x(8x＋8) ＝ 8x2＋8x ＝ 8(2x＋4)＋8x ＝ 24x ＋ 32
コツ「x² が出てきたら (2x＋4) に置きかえる」をくり返すだけ。

③ 式に代入してまとめる

x4−5x3−14x＋3 ＝ (24x＋32) − 5(8x＋8) − 14x ＋ 3 ＝ 24x＋32 − 40x − 40 − 14x ＋ 3 ＝ −30x − 5 ここへ x＝1−√5 を代入：−30(1−√5) − 5 ＝ −30＋30√5 − 5
答え30√5 − 35
検算：√5≒2.236 なので x≒−1.236。30√5−35≒32.08。もとの式に入れても x⁴≒2.33，−5x³≒9.44，−14x≒17.30，＋3 で合計≒32.07。ほぼ一致します。

複素数が等しい ⇒ 実部と虚部を比べる

(a2−3ab2) ＋ (3a2b−b2)i ＝ −i となる実数 a, b を求める。

a, b, c, d が実数のとき　a＋bi ＝ c＋di ⇔ a＝c かつ b＝d i ＝ √(−1)，i2 ＝ −1
やさしい解説：複素数ってなに？

「実部（ふつうの数の部分）＋ 虚部（i がついた部分）」の形の数です。たとえば 3＋2i の実部は 3、虚部は 2。

2つの複素数が等しいとは、実部どうし・虚部どうしがそれぞれ等しいということ。右辺の −i は「0 ＋ (−1)i」なので、実部は 0、虚部は −1 です。

① 実部と虚部を比べる

実部：a2 − 3ab2 ＝ 0　…(1) 虚部：3a2b − b2 ＝ −1　…(2) (1) を因数分解：a(a − 3b2) ＝ 0　⇒　a＝0 または a＝3b2

② a＝0 の場合

(2) に代入：−b2 ＝ −1　⇒　b2＝1　⇒　b＝±1

③ a＝3b² の場合

(2) に代入すると 3·(3b2)2·b − b2 ＝ −1、つまり 27b5 − b2 ＋ 1 ＝ 0。5次方程式になり、きれいな解は見つかりません。

答え(a, b) ＝ (0, 1), (0, −1)　（③の5次方程式はきれいに解けない）
⚠ 式の写し間違いに注意：③がきれいに解けないのは、問題の式が (a＋bi)³ ＝ −i の展開形 a³−3ab²＋(3a²b−b³)i の写し間違い（2乗と3乗）かもしれないからです。教科書で確認してください。
もしそうなら： a³−3ab²＝0 ⇒ a(a²−3b²)＝0。a＝0 なら −b³＝−1 で b＝1。a²＝3b² なら 8b³＝−1 で b＝−1/2，a＝±√3/2。

放物線と直線が交わる2点の距離

放物線 y＝x2−6x＋10 と直線 y＝3x＋k が P, Q で交わる。PQ ＝ 5√10 のとき、k を求める。

2点間の距離：A(x1, y1)，B(x2, y2) のとき　AB2 ＝ (x1−x2)2 ＋ (y1−y2)2 2次方程式 ax2＋bx＋c＝0 の解の差：|x1−x2| ＝ √D / |a|　（D＝b2−4ac）
やさしい解説
  • 距離の公式は中3の三平方の定理そのもの。横の差と縦の差を2乗して足すと、斜めの距離の2乗になります。
  • 解の差の公式は解の公式から出ます。解は x＝(−b±√D)/2a。＋とーの差をとると √D ÷ |a| だけ残ります。

① 交点の x 座標を x₁, x₂ とおく

x2−6x＋10 ＝ 3x＋k　⇒　x2 − 9x ＋ 10 − k ＝ 0 P(x1, 3x1＋k)，Q(x2, 3x2＋k)　← 直線 y＝3x＋k 上の点だから

② 距離 PQ を x₁−x₂ で表す

PQ2 ＝ (x1−x2)2 ＋ {(3x1＋k)−(3x2＋k)}2 ＝ (x1−x2)2 ＋ {3(x1−x2)}2 ＝ 10(x1−x2)2 PQ ＝ √10 |x1−x2|
なぜ 10 になる？直線の傾きが 3 なので、横に 1 進むと縦に 3 進みます。斜めの長さは √(1²＋3²)＝√10。つまり「横の差 × √10」が距離です（k は消えます）。

PQ＝5√10 より √10|x1−x2|＝5√10、よって |x1−x2| ＝ 5

③ 判別式から k を求める

D ＝ (−9)2 − 4(10−k) ＝ 81 − 40 ＋ 4k ＝ 41 ＋ 4k a＝1 なので |x1−x2| ＝ √(41＋4k) ＝ 5 両辺を2乗：41＋4k ＝ 25　⇒　4k ＝ −16
答えk ＝ −4
検算：k＝−4 なら x²−9x＋14＝0，(x−2)(x−7)＝0 で x＝2, 7。P(2, 2)，Q(7, 17)。PQ²＝5²＋15²＝250，PQ＝√250＝5√10 ✓。
また D＝25＞0 なので、たしかに異なる2点で交わっています。
テストでの流れ：①交点の x 座標を x₁, x₂ とおく → ②P, Q の座標を書く → ③距離の公式で PQ を出す → ④|x₁−x₂|＝5 → ⑤判別式で |x₁−x₂|＝√(41＋4k) → ⑥k＝−4
別解：解と係数の関係(x1−x2)2 ＝ (x1＋x2)2 − 4x1x2 ＝ 9² − 4(10−k) ＝ 41＋4k。同じ式になります。こちらで覚えている人はこちらでもOK。

k を定数とし、2次関数 f(x) = −x2 + 2kx − 2k2 + 3k + 4 がある。 (1) k = 2 のとき、y = f(x) のグラフの頂点の座標を求めよ。 (2) y = f(x) のグラフが点 (1, 0) を通るとき、k の値を求めよ。また、このとき y = f(x) のグラフと x軸の共有点の x座標を求めよ。 (3) y = f(x) のグラフが x軸の x ＞ 1 の部分と少なくとも一つの共有点をもつような k の値の範囲を考えよう。 　(i) f(1) ＞ 0 とする。このとき、グラフと x軸の x ＞ 1 の部分の共有点は、⓪ない　① 1個だけである　② ちょうど2個ある　のどれか。 　(ii) f(1) ＜ 0 とする。グラフが x軸の x ＞ 1 の部分と異なる2点で交わるような k の値の範囲を求めよ。 　(iii) グラフが x軸の x ＞ 1 の部分と少なくとも一つの共有点をもつような k の値の範囲を求めよ。 (4) グラフが x軸の x ≦ 1 の部分と少なくとも一つの共有点をもつような整数 k の値は、全部で何個あるか。

(1)　平方完成 → 頂点 (2)　f(1) = 0 を解く → k → 因数分解 → 共有点の x座標 (3)　準備（f(1)・軸・頂点の y座標）→ f(1) の符号で場合分け (4)　「x ≦ 1 に共有点をもたない」場合を除く
この問題の合言葉：「x軸との共有点 ＝ f(x) = 0 の解」。そして x = 1 を境に解が左右どちらにあるかは、頂点の y座標・軸の位置・f(1) の符号の3点セットで決まります。
(1)
頂点

k = 2 のときの頂点の座標（平方完成）

k = 2 のとき、y = f(x) のグラフの頂点の座標を求めよ。

y = a(x − p)2 + q のグラフの頂点は (p, q) x2 + bx = (x + b2)2 − (b2)2　（x の係数の半分を使う）
k = 2 のとき　f(x) = −x2 + 4x − 8 + 6 + 4 = −x2 + 4x + 2 = −(x2 − 4x) + 2 = −{(x − 2)2 − 4} + 2 = −(x − 2)2 + 6 よって、頂点の座標は (2, 6)
やさしい解説：平方完成のしくみ

x2 − 4x は、x の係数 −4 の半分 −2 を使って (x − 2)2 − 4 と書けます。（(x − 2)2 = x2 − 4x + 4 なので、余分な +4 を引いて調整します。）

グラフの形は y = −(x − 2)2 + 6。(x − 2)2 が 0 になる x = 2 のとき y が一番大きい（6）ので、頂点は (2, 6) です。

テストのポイント：−{ } を外すときの符号に注意。−{(x − 2)2 − 4} は、かっこの中の全部にマイナスをかけて −(x − 2)2 + 4 になります（−4 の項は +4 に変わる）。
f(x) = −(x − k)2 + k2 − 2k2 + 3k + 4 = −(x − k)2 − k2 + 3k + 4 頂点 (k, −k2 + 3k + 4)，軸 x = k，　−k2 + 3k + 4 = −(k + 1)(k − 4)
検算：この式に k = 2 を入れると、頂点は (2, −4 + 6 + 4) = (2, 6) ✓
答 (1)頂点の座標 (2, 6)　（ア ＝ 2，イ ＝ 6）
(2)
点を通る・共有点

点 (1, 0) を通るときの k と、x軸との共有点

y = f(x) のグラフが点 (1, 0) を通るとき、k の値を求めよ。また、このとき y = f(x) のグラフと x軸の共有点の x座標を求めよ。

グラフが点 (a, b) を通る ⇔ f(a) = b（x = a, y = b を式に代入すると成り立つ） x軸との共有点の x座標 ⇔ f(x) = 0 の解

① k の値を求める

グラフが点 (1, 0) を通るので　f(1) = 0 f(1) = −1 + 2k − 2k2 + 3k + 4 = −2k2 + 5k + 3 よって　−2k2 + 5k + 3 = 0　⇒　2k2 − 5k − 3 = 0 (2k + 1)(k − 3) = 0 ゆえに　k = −12，3
やさしい解説：2k² − 5k − 3 の因数分解（たすきがけ）

かけて 2·(−3) = −6、たして −5 になる2数は 1 と −6 です。そこで 2k2 − 6k + k − 3 と分けて、2k(k − 3) + (k − 3) = (2k + 1)(k − 3) とまとめます。展開して確かめると 2k2 − 6k + k − 3 = 2k2 − 5k − 3 ✓。

テストのポイント：f(1) の式は、このあと (3) でも使います。f(1) = −2k2 + 5k + 3 = −(2k + 1)(k − 3) の形まで因数分解しておくと、符号の調べ方が一気に楽になります。
答k = 3，−12　（ウ ＝ 3）

② 共有点の x座標を求める

f(x) = −x2 + 6x − 18 + 9 + 4 = −x2 + 6x − 5 f(x) = 0 ⇔ x2 − 6x + 5 = 0 ⇔ (x − 1)(x − 5) = 0　⇒　x = 1，5
f(x) = −x2 − x − 12 − 32 + 4 = −x2 − x + 2 f(x) = 0 ⇔ x2 + x − 2 = 0 ⇔ (x − 1)(x + 2) = 0　⇒　x = 1，−2
やさしい解説：f(x) = 0 の両辺に −1 をかける−x2 + 6x − 5 = 0 は、両辺に −1 をかけて x2 − 6x + 5 = 0 にすると、x² の係数が正になって因数分解しやすくなります（右辺は 0 なので、かけても変わりません）。
検算：どちらも x = 1 が解に入っています（点 (1, 0) を通るので当然）。2つの解の和は、x2 − 2kx + … = 0 の x の係数から 2k のはず。k = 3 → 1 + 5 = 6 ✓、k = −12 → 1 + (−2) = −1 ✓。
答k = 3 のとき x = 1，5　（カ ＝ 5）　／　k = −12 のとき x = 1，−2　（キ ＝ −2）

解の位置

やさしい解説：問題を言いかえるx軸との共有点の x座標は f(x) = 0 の解です。「x軸の x ＞ 1 の部分と共有点をもつ」とは、f(x) = 0 の解のうち、1 より大きいものが少なくとも 1 つあるということです。

準備：3つの材料をそろえる

① f(1) の符号：f(1) = −2k2 + 5k + 3 = −(2k + 1)(k − 3) 　　f(1) ＞ 0 ⇔ −12 ＜ k ＜ 3 　　f(1) = 0 ⇔ k = −12，3 　　f(1) ＜ 0 ⇔ k ＜ −12，3 ＜ k ② 軸の位置：x = k　（(1) の f(x) = −(x − k)2 − (k + 1)(k − 4) より） ③ 頂点の y座標：−k2 + 3k + 4 = −(k + 1)(k − 4) 　　x軸と共有点をもつ ⇔ 頂点の y座標 ≧ 0 ⇔ −1 ≦ k ≦ 4 　　異なる2点で交わる ⇔ 頂点の y座標 ＞ 0 ⇔ −1 ＜ k ＜ 4
やさしい解説：なぜこの3つを調べるの？
  • ① f(1)：x = 1 は「x ＞ 1」の境目です。そこでグラフが x軸の上か下かが分かれば、境目が2つの共有点の間にあるのか、外にあるのかが分かります。
  • ② 軸 x = k：2つの共有点は軸を中心に左右対称、つまり軸は2つの共有点のちょうど真ん中です。共有点が 1 の右にあるか左にあるかを判断するのに使います。
  • ③ 頂点の y座標：x² の係数が −1（マイナス）なので、グラフは山の形（上に凸）です。頂点が一番高い点なので、頂点が x軸より下だと、グラフ全体が x軸より下に沈んで共有点がありません。（これは判別式 D と同じ内容で、D = 4(−k2 + 3k + 4) です。）

下の4枚は、k の値を変えたときのグラフです。黄色い帯が x軸の x ＞ 1 の部分、赤い点がその帯の上にある共有点です。

(i) f(1) ＞ 0 のとき

f(1) ＞ 0 より、グラフは x = 1 で x軸の上にあるので、x軸と異なる2点 α, β (α ＜ β) で交わる。 グラフは上に凸なので、f(x) ＞ 0 となるのは α ＜ x ＜ β のときだけである。 f(1) ＞ 0 より α ＜ 1 ＜ β よって、x ＞ 1 の部分にある共有点は β の 1個だけである。
やさしい解説山の形のグラフで、x軸より上にある部分は「2つの交点の間」だけです。x = 1 がその間に入っている（f(1) ＞ 0）なら、1 より右に交点が1つ、左に交点が1つ。上の図の ① がこの場合です。
答 (i)① 1個だけである　（ク ＝ ①）

(ii) f(1) ＜ 0 で、x ＞ 1 の部分と異なる2点で交わる k の範囲

やさしい解説：f(1) ＜ 0 のときの2つの共有点

山の形のグラフで f(1) ＜ 0 なら、x = 1 は2つの交点の間ではなく外にあります。だから2つの交点は、ともに 1 の右かともに 1 の左のどちらかです（図の ②③）。

ともに右にあるのは、2つの交点の真ん中である軸が 1 より右にあるとき。さらに、そもそも2点で交わる必要があります。

(A) 異なる2点で交わる：頂点の y座標 ＞ 0　⇒　−1 ＜ k ＜ 4 (B) 軸が 1 より右：k ＞ 1 (C) 仮定 f(1) ＜ 0：k ＜ −12，3 ＜ k
グラフは上に凸で f(1) ＜ 0 なので、x ＞ 1 の部分で異なる2点で交わるのは、次の3つが成り立つときである。 (A) 頂点の y座標 −k2 + 3k + 4 ＞ 0　⇔　(k + 1)(k − 4) ＜ 0　⇔　−1 ＜ k ＜ 4 (B) 軸 x = k が 1 より大きい　⇔　k ＞ 1 (C) f(1) ＜ 0　⇔　k ＜ −12 または 3 ＜ k (A)(B)(C) の共通部分をとって　3 ＜ k ＜ 4
検算：k = 3.5 は 3 ＜ k ＜ 4 の中。f(x) = −x² + 7x − 10 = −(x − 2)(x − 5) で、解は x = 2, 5。どちらも x ＞ 1 ✓（図の ②）。
テストのポイント：(A)(B)(C) は3つとも必要です。たとえば k = 4.5 は (B)(C) を満たしますが (A) を満たさず共有点なし（図の ④）。k = −0.75 は (A)(C) を満たしますが (B) を満たさず、共有点は x ＜ 1 側にしかありません（図の ③）。
答 (ii)3 ＜ k ＜ 4　（ケ ＝ 3，コ ＝ 4）

AD は ∠A の二等分線なので　∠BAD = ∠DAC = 30° △ABD = (1/2) · AB · AD · sin 30°，　△ADC = (1/2) · AC · AD · sin 30° △ABC = △ABD + △ADC = (1/2) · AD · sin 30° · (AB + AC) 　　　= (1/2) · AD · (1/2) · (6 + 8) = (7/2) AD　…① 一方、△ABC = (1/2) · 6 · 8 · sin 60° = 12√3　…② ①と②より　(7/2) AD = 12√3　⇒　AD = 24√3 / 7
やさしい解説：sin の値が 1/2 になる理由

sin 30° = 1/2、sin 60° = √3/2 は、30°・60°・90° の直角三角形（辺の比 1 : √3 : 2）から覚えられます。sin は「斜辺に対する高さの割合」なので、30° では高さが斜辺の半分になります。

テストのポイント：面積の式は「2辺とその間の角」で書く。△ABD では AB と AD の間の角 ∠BAD = 30°、△ADC では AD と AC の間の角 ∠DAC = 30° を使うこと。角を取り違えると答えが変わります。
検算（別の公式）：AD = 2bc cos(A/2) / (b + c) ＝ 2 · 6 · 8 · cos 30° / 14 ＝ 96 · (√3/2) / 14 ＝ 48√3 / 14 ＝ 24√3 / 7 ✓。

別解：角の二等分線の長さの公式

AD² = bc [ 1 − a² / (b + c)² ]　（b = AC，c = AB，a = BC）
AD² = 6 · 8 [ 1 − (2√13)² / (6 + 8)² ] = 48 (1 − 52/196) = 48 · 144/196 = 1728/49 AD は正なので　AD = 24√3 / 7
やさしい解説：公式は面積の考え方から出せる

この公式は、三角形 ABD と ACD に余弦定理を使うと導けます。公式を覚えるより、「面積で考えれば求まる」と分かっているほうが、忘れたときに役立ちます。

平均　ȳ = −2 × 21 + 3 = −39 分散　V(y) = (−2)² × 12 = 48
やさしい解説：なぜ分散は b を無視するの？

全部の値に同じ数を足しても、「平均からのズレ」は変わりません。例えば、どの点数にも 3 点を足すと、平均は 3 点上がりますが、一人ひとりの平均との差はそのままです。だから分散は変わりません。

一方、−2 倍すると、ズレも 2 倍になります。分散は「ズレの2乗の平均」なので、(−2)² = 4 倍になります。

テストのポイント：平均は「そのまま代入」、分散は「定数の2乗倍」。分散に「+3」を足さないこと、また「−2」を2乗して「+4」にすることを確認しましょう。
