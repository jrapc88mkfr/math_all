問題
第6問（記述式）

円柱と空間ベクトル

座標空間において、A = (5, 0, 0)、B = (−75, 245, 0) とする。円柱 x² + y² = 25、0 ≦ z ≦ 10 の側面上に点 C = (a, b, c) をとり、|CA| = |CB| を満たす。点 C を通る z軸に平行な直線と xy平面との交点を D とする。 (1) (a, b) を求めよ。 (2) D = (−3, −4, 0) のとき、DA・DB を求めよ。 (3) (2) の D について、cos∠ADB を求めよ。 (4) C = (3, 4, c) のとき、|CA|² を求めよ。

(1)　距離の2乗を比べる → 成分の式 → 円柱の式と合わせる (2)　D から A, B へのベクトル（終点 − 始点）→ 内積（成分どうしの積の和） (3)　内積の公式を変形して cos を求める → 角度の大きさを判断 (4)　A − C の成分 → 成分の2乗の和
この問題の合言葉：「距離の比べは2乗で」「ベクトルは終点 − 始点」「角度は内積で」。
(1)
距離が等しい条件

(a, b) を求める

C は円柱の側面上にあり、|CA| = |CB| を満たす。(a, b) を求めよ。

2点 P(x₁, y₁, z₁)，Q(x₂, y₂, z₂) の距離：|PQ|² = (x₂ − x₁)² + (y₂ − y₁)² + (z₂ − z₁)² 円柱の側面：a² + b² = 25　…①
|CA|² = (a − 5)² + b² + c² |CB|² = (a + 75)² + (b − 245)² + c² |CA|² = |CB|² を展開して整理すると a² − 10a + 25 + b² + c² = a² + 145a + 4925 + b² − 485b + 57625 + c² −10a + 25 = 145a − 485b + 25　（4925 + 57625 = 25） −645a = −485b　⇒　4a = 3b　…② ②より a = 3k，b = 4k とおき、①に代入：9k² + 16k² = 25k² = 25　⇒　k = ±1 よって (a, b) = (3, 4)　または　(−3, −4)
やさしい解説：なぜ2つ出てくるの？

「2点から等しい距離にある点」の集まりは、2点を結ぶ線分の垂直二等分線です。ここでは、その直線（上の図の赤い点線）と円柱の底の円が交わる2点が候補になります。直線と円は2点で交わることがあるので、答えも2つです。

また、a², b², c² は両辺に同じものがあるので、引き算すると消えます。だから c の値に関係なく、(a, b) だけが決まります。

テストのポイント：展開のときの符号に注意。(a + 75)² の真ん中は +145a、(b − 245)² の真ん中は −485b です。また、候補が2つ出たら、どちらを使っているかを必ず区別する（(2) 以降で使う座標が違うため）。
答 (1)(a, b) = (3, 4)　または　(−3, −4)
(2)
ベクトルの内積

D = (−3, −4, 0) のとき DA・DB

点 D を (−3, −4, 0) とするとき、DA・DB を求めよ。

DA ＝ A − D（終点 A − 始点 D） 成分で表すと：ベクトル a = (a₁, a₂, a₃)，b = (b₁, b₂, b₃) のとき　a・b = a₁b₁ + a₂b₂ + a₃b₃
DA = A − D = (5 + 3, 0 + 4, 0) = (8, 4, 0) DB = B − D = (−75 + 3, 245 + 4, 0) = (85, 445, 0) DA・DB = 8 · 85 + 4 · 445 + 0 · 0 = 645 + 1765 = 2405 = 48
やさしい解説：内積とは

内積は「成分どうしを掛けて、全部たす」だけです。z成分は両方とも 0 なので、3番目の掛け算は 0 になって消えます。だから平面の問題と同じ計算になります。

内積の答えがプラスなので、∠ADB は 90° より小さい鋭角です（この角度は (3) で確かめます）。

テストのポイント：ベクトルの向きに注意。DA は D から A へ向かうので「A − D」。「D − A」と逆にすると、成分の符号がすべて逆になります（内積の値は変わりませんが、答案の書き方として誤りです）。
検算：成分を使わず、x成分どうし・y成分どうしの積の和で計算すると、8 · 1.6 + 4 · 8.8 = 12.8 + 35.2 = 48 ✓。
答 (2)DA・DB = 48
(3)
内積と角度

cos∠ADB を求める

(2) の D について、cos∠ADB を求めよ。

DA・DB = |DA| |DB| cos∠ADB よって　cos∠ADB = DA・DB / (|DA| |DB|)
|DA| = √(8² + 4²) = √80 = 4√5 |DB|² = (85)² + (445)² = 64 + 193625 = 200025 = 80　より　|DB| = 4√5 cos∠ADB = 48(4√5)(4√5) = 4880 = 35
やさしい解説：cos で角度の大きさを比べる

cos の値は、角度が大きいほど小さくなります（0° で 1、90° で 0、180° で −1）。だから、cos の値を基準の値と比べると、角度の大きさが分かります。

  • cos60° ＝ 12 を基準にすると、35 ＞ 12（35 ＝ 0.6、12 ＝ 0.5）
  • cos の値が大きい方が角度は小さいので、∠ADB ＜ 60°
  • 電卓で計算すると、約 53° です（cos⁻¹(0.6)）。
テストのポイント：答えは「cos∠ADB = 3/5」と書き、角度の大きさ（60° より小さい）も続けて書くと、問いの意図に合います。また、この角度は D(−3, −4, 0) のときのものです。D(3, 4, 0) の場合に同じ値を使うと誤りになるので、どの D かを必ず確認しましょう。
検算：|DA|² ＝ 80、|DB|² ＝ 80、DA・DB ＝ 48。cos ＝ 48 / 80 ＝ 3/5 ✓。また、cos が 1 以下であることも確認できる（3/5 ＜ 1）。
答 (3)cos∠ADB = 35　（∠ADB は 60° より小さい）
(4)
空間の距離

C = (3, 4, c) のとき |CA|²

点 C を (3, 4, c) とするとき、|CA|² を求めよ。

|CA|² ＝ （A の x − C の x）² ＋ （A の y − C の y）² ＋ （A の z − C の z）² （成分ごとの差の2乗をたす。三平方の定理を空間に広げたもの）
CA ＝ A − C ＝ (5 − 3, 0 − 4, 0 − c) ＝ (2, −4, −c) |CA|² ＝ 2² + (−4)² + (−c)² ＝ 4 + 16 + c² ＝ 20 + c²
やさしい解説：空間の距離は3方向の差

平面の距離は「横の差と縦の差」の2乗の和でした。空間では、ここに高さの差の2乗が加わるだけです。今回は、x方向の差 2、y方向の差 −4、z方向の差 −c で、それぞれ2乗してたします。

z方向の差は −c ですが、2乗すると符号が消えるので、c² になります。

テストのポイント：「A − C」と「C − A」のどちらでも、2乗すれば同じ値になります。ただし、途中で成分の引き算を間違えないこと（A の y座標は 0、C の y座標は 4 なので、0 − 4 = −4）。
検算：c ＝ 0 のとき、C(3, 4, 0) と A(5, 0, 0) の距離は、平面の距離 √(2² + 4²) ＝ √20 なので、|CA|² ＝ 20 ✓。
答 (4)|CA|² = 20 + c²
