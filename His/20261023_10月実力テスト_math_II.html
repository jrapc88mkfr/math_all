問題1
確率

袋から玉を取り出す（赤を R、それ以外を N）

袋に赤玉2個、黄玉1個、青玉1個（合計4個）が入っている。1個取り出して色を確認し、袋に戻す操作を4回くり返す。 (1) 4回連続して赤玉を取り出す確率、少なくとも1回は赤玉を取り出す確率を求めよ。 (2) ちょうど3回連続して赤玉、ちょうど2回連続して赤玉を取り出す確率を求めよ。 (3) 連続して赤玉を取り出さない確率、および連続して赤玉を取り出さないとき、赤玉を1回も取り出していない条件付き確率を求めよ。

赤玉の確率 ＝ 2/4 ＝ 1/2、赤玉以外（N）の確率 ＝ 1/2。毎回戻すので各回は独立。 4回の結果は 2⁴ ＝ 16 通り。どの並びも確率は (1/2)⁴ ＝ 1/16
やさしい解説：16通りを全部書いてみる

4回の結果は、R か N の組み合わせで、全部で16通りです。下の表は16通りを並べたものです。色は、(2)・(3) で数える条件ごとに分けています。

表の読み方
  • 紫：RR（赤が2回続けて並ぶ）を含まない＝(3)の8通り
  • 緑：RR がちょうど1組だけ（RRR を含まない）＝(2)の5通り
  • 青：RRR（3回続く）＝(2)の2通り
  • 金：RRRR（4回続く）＝(1)の1通り

4つのグループで16通りすべてを数えられているので、数え漏れがないことも確認できます（8 + 5 + 2 + 1 = 16）。

(1)

4回連続して赤玉：RRRR の1通り　⇒　(1/2)⁴ = 1/16 少なくとも1回は赤玉：「4回とも赤玉以外」の余事象を使う　⇒　1 − (1/2)⁴ = 15/16
テストのポイント：「少なくとも1回」は、「1回も起こらない」の余事象で計算すると速い。

(2)

ちょうど3回連続して赤玉：RRRN，NRRR の2通り（RRRR は4回なので除く）　⇒　2 × 1/16 = 1/8 ちょうど2回連続して赤玉（RR が1組、RRR はない）：RRNN，RRNR，RNRR，NRRN，NNRR の5通り　⇒　5 × 1/16 = 5/16
やさしい解説：「ちょうど」と「以上」の違い

「ちょうど3回連続」は、RRR が続いて、その前後が R でない形です。RRRR は4回続くので、「ちょうど3回」には入りません。

テストのポイント：「ちょうど2回」と書かれたら、RRR が含まれていないかを必ず確認する。RRNR や RNRR のように、RR が前後どちらかにあるものも忘れない。

(3)

B：赤玉が連続しない　⇒　表の紫の8通り（NNNN，RNNN，NRNN，NNRN，NNNR，RNRN，RNNR，NRNR）　⇒　8/16 = 1/2 A：赤玉を1回も取り出さない（NNNN）　⇒　P(A) = 1/16 A ⊂ B なので　P(A ∩ B) = P(A) = 1/16 P(A|B) = P(A ∩ B)/P(B) = (1/16)/(1/2) = 1/8
やさしい解説：条件付き確率は「範囲をしぼる」

「連続しない」という条件のもとで、その中の8通りだけを見ます。そのうち「赤が1回も出ない」のは NNNN の1通りだけなので、1/8 です。

式で書くと、P(A|B) = P(A∩B)/P(B)。「条件 B の中で A が起こる割合」です。

検算：条件付き確率の式で、8通り（紫）のうち1通り（NNNN）なので 1/8 ✓。
答 (1)〜(3)(1) 1/16，15/16　(2) 1/8，5/16　(3) 1/2，1/8
問題2
対数・最大最小

log₂x + log₂y = 3 のとき

x > 0，y > 0 で log₂x + log₂y = 3 のとき、 (1) xy の値を求めよ。 (2) x² + y² の最小値と、そのときの x, y を求めよ。 (3) (log₂x)³ + (log₂y)³ の最小値と、そのときの x, y を求めよ。

対数の足し算は掛け算：log₂x + log₂y = log₂(xy) 対数の掛け算は足し算：log₂(xy) = log₂x + log₂y　（式を見て向きを逆にできるように）

(1)

log₂(xy) = 3　⇒　xy = 2³ = 8

(2)

(x − y)² ≥ 0 より　x² − 2xy + y² ≥ 0　⇒　x² + y² ≥ 2xy = 16 等号成立は x = y のとき。xy = 8 と合わせて x² = 8，x > 0 より x = y = 2√2 よって最小値は 16（x = y = 2√2 のとき）
やさしい解説：図で見ると「接したところが最小」

x² + y² = r² は原点中心の円です。xy = 8 の曲線に、円が外から接するところで r² が最小になります。図の接点が (2√2, 2√2) で、そのとき r² = 8 + 8 = 16 です。

「二乗の和 ≥ 2 × 積」は、(x − y)² ≥ 0 を展開すれば必ず出てきます。

テストのポイント：最小値だけでなく、等号が成り立つ条件（x = y）を書き、そこから x, y を求める。x, y > 0 の確認も忘れない。

(3)

a³ + b³ = (a + b)³ − 3ab(a + b)
a = log₂x，b = log₂y とおくと、条件は a + b = 3 a³ + b³ = 27 − 3ab · 3 = 27 − 9ab ab を最大にすると a³ + b³ は最小になる。(a − b)² ≥ 0 より (a + b)² ≥ 4ab　⇒　9 ≥ 4ab　⇒　ab ≤ 9/4 等号は a = b = 3/2 のとき。よって最小値は　27 − 9 × 9/4 = 27/4 a = b = 3/2 より x = y = 2^(3/2) = 2√2
やさしい解説：なぜ ab を大きくすると小さくなる？

a + b = 3 は変わらないので、a³ + b³ = 27 − 9ab の形になります。式の中で ab だけが変化する部分で、ab が大きいほど引く量が大きくなり、全体は小さくなります。

検算：x = y = 2√2 のとき log₂x = 3/2，a³ + b³ = 2 × (3/2)³ = 2 × 27/8 = 27/4 ✓。
テストのポイント：対数の値 a, b に置きかえると、和の一定の条件が見えやすい。最後に a, b から x, y に戻すのを忘れない。
答 (1)〜(3)(1) xy = 8　(2) 最小値 16，x = y = 2√2　(3) 最小値 27/4，x = y = 2√2
問題3
ベクトル（四面体）

内分点と平面・直線の交点

四面体 OABC において、辺 OA を 1:3 に内分する点を P、辺 OB を 1:2 に内分する点を Q、辺 AC の中点を R とする。平面 PQR と辺 BC の交点を S とする。OA = a，OB = b，OC = c とする。 (1) PQ，PR を a，b，c で表せ。 (2) BS : SC = t : (1 − t) とおく。PS を a，b，c，t で表せ。また、t の値を求めよ。 (3) 直線 PS と直線 QR の交点を T とする。PT : TS，QT : TR をそれぞれ求めよ。

OP 上で OP : PA = 1 : 3 ⇒ OP = (1/4) a　（全体を 4 等分して 1 つ分） OQ : QB = 1 : 2 ⇒ OQ = (1/3) b　（全体を 3 等分して 1 つ分） R は AC の中点 ⇒ OR = (a + c)/2
やさしい解説：「1:3」の意味

OP : PA = 1 : 3 は、線分 OA を 4 等分して、O から 1 つ分のところに P があるという意味です。だから OP は OA の 1/4 です。「1:3 の 1 は近い方（O 側）」と覚えておくと間違えにくくなります。

(1)

PQ = OQ − OP = (1/3)b − (1/4)a = −(1/4)a + (1/3)b PR = OR − OP = (a + c)/2 − (1/4)a = (1/4)a + (1/2)c
テストのポイント：ベクトルは「終点 − 始点」。PQ は P から Q へ行くので、OQ − OP。

(2)

BS : SC = t : (1 − t) より　OS = (1 − t)b + tc PS = OS − OP = −(1/4)a + (1 − t)b + tc S は平面 PQR 上にあるので、PS = uPQ + vPR とおける。 右辺を整理すると　a の係数：−u/4 + v/4，b の係数：u/3，c の係数：v/2 a，b，c は同じ平面上にない（一次独立）ので、係数を比べる： 　−1/4 = −u/4 + v/4　⇒　−1 = −u + v　…① 　1 − t = u/3　⇒　u = 3(1 − t)　…② 　t = v/2　⇒　v = 2t　…③ ②，③を①に代入：−1 = −3(1 − t) + 2t = −3 + 5t　⇒　t = 2/5 よって　PS = −(1/4)a + (3/5)b + (2/5)c
検算：t = 2/5 のとき、u = 3 × 3/5 = 9/5、v = 4/5。PS = (9/5)PQ + (4/5)PR の a 係数：−(9/5)(1/4) + (4/5)(1/4) = −5/20 = −1/4 ✓。
やさしい解説：なぜ係数を比べてよい？

a，b，c は三角錐の3辺で、同じ平面上にないので、「a の何倍＋b の何倍＋c の何倍」の形は1通りに決まります。だから、左辺と右辺で a，b，c の係数がそれぞれ等しくなります。

テストのポイント：「平面上の点」は、その平面内の2つのベクトルの和で表す。係数を比べる式は、①a，②b，③c の順にていねいに立てる。

(3)

T は直線 PS 上：PT = kPS　⇒　OT = (1 − k)/4 · a + 3k/5 · b + 2k/5 · c　…① T は直線 QR 上：QT = mQR，QR = (1/2)a − (1/3)b + (1/2)c 　⇒　OT = (m/2)a + (1 − m)/3 · b + (m/2)c　…② ①，②の a の係数と c の係数を比べる：(1 − k)/4 = m/2，　2k/5 = m/2 2式から (1 − k)/4 = 2k/5　⇒　5(1 − k) = 8k　⇒　k = 5/13，　m = 4k/5 = 4/13 b の係数で確かめる：3k/5 = 3/13，(1 − m)/3 = (9/13)/3 = 3/13 ✓ PT : TS = k : (1 − k) = 5/13 : 8/13 = 5 : 8 QT : TR = m : (1 − m) = 4/13 : 9/13 = 4 : 9
やさしい解説：交点は「2通りに表して等しい」

T は2つの直線の両方にあるので、OT を2通りの式で表せます。その2つの式が等しいとき、係数が一致します。これが「交点を2通りに表す」方法です。

「PT : TS = k : (1 − k)」は、PS 全体を 1 としたとき、P から T までが k の割合だからです。

検算：図で、T は PS の約 38%（5/13 ≒ 0.385）の位置にあり、QR の約 31%（4/13 ≒ 0.31）の位置にあります。図の交点の位置とも一致します。
テストのポイント：係数比較のとき、k と m の意味（何の割合か）を書いておくと、PT : TS と QT : TR を取り違えない。
答 (1)〜(3)(1) −(1/4)a + (1/3)b，　(1/4)a + (1/2)c　(2) PS = −(1/4)a + (3/5)b + (2/5)c，t = 2/5　(3) PT : TS = 5 : 8，QT : TR = 4 : 9
問題4
数列

和 Sₙ から漸化式をつくる

数列 {aₙ} は a₁ = 1，初めから第 n 項までの和を Sₙ とすると、Sₙ₊₁ = 4aₙ + 3（n = 1, 2, 3, …）を満たす。 (1) a₂ を求めよ。また、aₙ₊₂ を aₙ₊₁ と aₙ で表せ。 (2) bₙ = aₙ₊₁ − 2aₙ とおく。数列 {bₙ} の一般項を求めよ。 (3) 数列 {aₙ} の一般項を求めよ。

Sₙ₊₁ − Sₙ = aₙ₊₁　（和の差は、次の1項） この問題では、Sₙ₊₂ − Sₙ₊₁ = aₙ₊₂ を使う。

(1)

n = 1 を代入：S₂ = 4a₁ + 3 = 7　　S₂ = a₁ + a₂ より　1 + a₂ = 7　⇒　a₂ = 6 Sₙ₊₂ = 4aₙ₊₁ + 3，Sₙ₊₁ = 4aₙ + 3 の差をとると Sₙ₊₂ − Sₙ₊₁ = 4aₙ₊₁ − 4aₙ　⇒　aₙ₊₂ = 4aₙ₊₁ − 4aₙ
テストのポイント：添字に注意。Sₙ₊₂ − Sₙ₊₁ は aₙ₊₂（第 n+2 項）。

(2)

bₙ₊₁ = aₙ₊₂ − 2aₙ₊₁ = (4aₙ₊₁ − 4aₙ) − 2aₙ₊₁ = 2aₙ₊₁ − 4aₙ = 2(aₙ₊₁ − 2aₙ) = 2bₙ よって {bₙ} は公比 2 の等比数列。b₁ = a₂ − 2a₁ = 6 − 2 = 4 bₙ = 4 · 2ⁿ⁻¹ = 2ⁿ⁺¹
やさしい解説：「2倍になる」形を見つける

(1) の式 aₙ₊₂ = 4aₙ₊₁ − 4aₙ を、「aₙ₊₁ − 2aₙ」の形にまとめ直すと、同じ比（2倍）が出てくるのがポイントです。

(3)

aₙ₊₁ − 2aₙ = 2ⁿ⁺¹ より　aₙ₊₁ = 2aₙ + 2ⁿ⁺¹ cₙ = aₙ / 2ⁿ⁻¹ とおくと、aₙ = 2ⁿ⁻¹ cₙ，aₙ₊₁ = 2ⁿ cₙ₊₁ 2ⁿ cₙ₊₁ = 2 · 2ⁿ⁻¹ cₙ + 2ⁿ⁺¹ = 2ⁿ cₙ + 2ⁿ⁺¹　⇒　cₙ₊₁ = cₙ + 2 c₁ = a₁ = 1，公差 2 の等差数列　⇒　cₙ = 2n − 1 よって　aₙ = (2n − 1) · 2ⁿ⁻¹
やさしい解説：2ⁿ⁻¹ で割ると、ふつうの数列になる

aₙ は 1, 6, 20, 56, 144 と急に大きくなります。そこで 2ⁿ⁻¹ で割ると、cₙ = 1, 3, 5, 7, 9 と、規則正しく増える数列になります。これが「指数の部分をそろえる」考え方です。

検算：a₃ = (2·3 − 1)·2² = 5 · 4 = 20。漸化式から a₃ = 4a₂ − 4a₁ = 24 − 4 = 20 ✓。
テストのポイント：最後の一般項は、n = 1, 2 を代入して確かめると、ミスを防げる。
答 (1)〜(3)(1) a₂ = 6，aₙ₊₂ = 4aₙ₊₁ − 4aₙ　(2) bₙ = 2ⁿ⁺¹　(3) aₙ = (2n − 1)·2ⁿ⁻¹
問題5
円・直線・領域

2つの円と領域 D、直線が D と交わる条件

2つの円 C₁：x² + y² − 1 = 0，C₂：x² + y² − 4x − 2y + 1 = 0 がある。 (1) C₁，C₂ の交点の座標を求めよ。 (2) (x² + y² − 1)(x² + y² − 4x − 2y + 1) ≤ 0 で表される領域 D を図示せよ。 (3) 直線 ℓ：y = m(x − 1) − 2 と領域 D が共有点をもつような m の範囲を求めよ。

(1) 交点

2つの円の式の差をとると直線になる（交点を通る直線）。 C₂ − C₁ ： −4x − 2y + 2 = 0　⇒　y = 1 − 2x
y = 1 − 2x を x² + y² = 1 に代入：x² + (1 − 2x)² = 1 5x² − 4x = 0　⇒　x(5x − 4) = 0　⇒　x = 0，4/5 y = 1 − 2x より　x = 0 のとき y = 1，x = 4/5 のとき y = −3/5 よって交点は (0, 1)，(4/5, −3/5)
検算：(0, 1) を C₂ に代入：0 + 1 − 0 − 2 + 1 = 0 ✓。(4/5, −3/5) を C₂ に代入：16/25 + 9/25 − 16/5 + 6/5 + 1 = 1 − 2 + 1 = 0 ✓。

(2) 領域 D

（x² + y² − 1）と（x² + y² − 4x − 2y + 1）の積が 0 以下 ⇔ 一方が 0（円周上），または 2つの符号が逆 f₁ = x² + y² − 1 ＝ 0 は C₁ の円周，f₁ ≤ 0 は C₁ の内側（円盤の内部） f₂ ≤ 0 は C₂ の内側，f₂ ≥ 0 は C₂ の外側
やさしい解説：「片方の内側・もう片方の外側」

2つの数の積が 0 以下になるのは、「一方が 0」か「符号が逆」のときです。つまり、C₁ の内側かつ C₂ の外側、または C₂ の内側かつ C₁ の外側の部分です。2つの円が重なった部分は、どちらも内側なので積は正になり、含まれません。

円周上は積が 0 になるので、円周も含まれます。

テストのポイント：「≤ 0」は、円周を含む。また「重なった部分は除く」ことを、図で必ず確認する。

(3) 直線と領域 D が交わる条件

円周は D に含まれる。直線が C₁ か C₂ のどちらかと交わるなら、その交点は D の中にある。 逆に、どちらの円とも交わらない直線は、2つの円の外側だけを通るので、D とは交わらない。 よって「C₁ と交わる」または「C₂ と交わる」の範囲を合わせればよい。
やさしい解説：なぜ円と交われば十分？

直線は円盤の中だけを通ることはできません（まっすぐ伸びて外に出るから）。直線が2つの円のどちらとも交わらなければ、直線全体は円の外にあるので、D にも入りません。

逆に、円と交わればその交点は円周上の点で、円周は D に含まれます。

円の中心から直線までの距離 ≤ 半径 直線は mx − y − m − 2 = 0（y = m(x − 1) − 2 を変形）。点と直線の距離の公式を使う。
C₁（中心 (0, 0)，半径 1）と交わる条件 |m + 2| / √(m² + 1) ≤ 1　⇒　(m + 2)² ≤ m² + 1　⇒　4m + 4 ≤ 1　⇒　m ≤ −3/4 C₂（中心 (2, 1)，半径 2）と交わる条件 |2m − 1 − m − 2| / √(m² + 1) ≤ 2　⇒　|m − 3| ≤ 2√(m² + 1) (m − 3)² ≤ 4(m² + 1)　⇒　3m² + 6m − 5 ≥ 0 3m² + 6m − 5 = 0 の解は m = (−3 ± 2√6)/3。下に凸ではなく上に開く式なので、m ≤ (−3 − 2√6)/3，または m ≥ (−3 + 2√6)/3 2つの条件を合わせる。(−3 − 2√6)/3 ≈ −2.63 は m ≤ −3/4 に含まれ、(−3 + 2√6)/3 ≈ 0.63 は m ≤ −3/4 に含まれない。 よって求める範囲は　m ≤ −3/4　または　m ≥ (−3 + 2√6)/3
検算：m = 0（図の破線）は、C₁ とも C₂ とも交わらない（m = 0 は範囲 −3/4 < m < 0.63 の中）✓。m = −3/4 のとき C₁ に接する（距離がちょうど 1）✓。
テストのポイント：元の解答の「−3/4 ≤ m ≤ (−3+2√6)/3」は誤り。円周も D に含まれるので、C₁ と交わる範囲（m ≤ −3/4）はそのまま答えに入る。2つの範囲の「または」を正しく書く。
