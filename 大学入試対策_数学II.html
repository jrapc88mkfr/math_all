(1) ① 関数 y = 2cos x の周期のうち、正で最小のものを求めよ。 　　② 関数 y = 2cos 2x の周期のうち、正で最小のものを求めよ。 　　③ 次の等式を利用して、関数 y = 2cos(2x + π3) のグラフが、関数 y = 2cos 2x のグラフを x軸方向にどれだけ平行移動したものか答えよ。　2cos(2x + π3) = 2cos 2(x + π6) (2) グラフを利用して、方程式 sin x = 2cos(2x + π3) の解の個数を求めよ。 　　① 0 ≦ x ≦ π　　② 0 ≦ x ≦ 2π

関数 y = 2cos x の周期のうち、正で最小のものを求めよ。

y = a cos(bx + c) の　周期 ＝ 2π｜b｜　　振幅 ＝ ｜a｜ cos x の周期は 2π（sin x も同じ）

やさしい解説：周期と振幅

周期は「同じ形がくり返す、1回分の横の長さ」です。振幅は波の高さ（真ん中から山までの高さ）です。

前につく 2 は、グラフを縦に 2倍に引きのばすだけ（振幅が 1 → 2）。横の長さは変わらないので、周期は 2π のままです。

テストのポイント：前の係数 2 は振幅（高さ）。周期に関係するのは x にかかる係数だけです。2 を見て「周期が変わる」と考えないこと。
答 (1)①2π

cos 2x では、x が進むと「2x」はその2倍の速さで進みます。x が 0 から π まで進むと、2x は 0 から 2π まで進んで、cos が1回分の波を終えます。だから周期は π（もとの半分）です。

確かめ：2cos 2(x + π) = 2cos(2x + 2π) = 2cos 2x となり、x を π ずらしても同じ式に戻ります ✓。

テストのポイント：「正で最小」と聞かれています。2π, 3π, … もすべて周期ですが、答えるのはいちばん小さい正の周期 πです。

第2問（記述式）人口の増減と常用対数

📋 問題の背景

ある地域の0歳から14歳までの人口が減少しています。このように実際の変化を数学で予測するために「常用対数」という強力な道具を使います。

2020年123万人
2022年111万人
2024年100万人
（1）毎年の人口減少倍率を求める

毎年の減少倍率 r の常用対数を求めるプロセス

12年間で何倍になるかを式にする

2020年から2022年は2年間です。毎年 r 倍になるということは：

  • 2020年：123万人
  • 2021年：123 × r 万人
  • 2022年：123 × r × r = 123 × r2 万人
🔵 なぜこうなるのか（中学の知識）

毎年同じ倍率で変化するとき、その倍率を繰り返し掛けます。これは「等比数列」という数列です。例えば、毎年2倍ずつ増える人口なら、1年後は2倍、2年後は2 × 2 = 4倍になります。ここでは減少するので、r は1より小さい数（0.9付近）です。

問題文では、111/123 ≈ 0.9 と 100/111 ≈ 0.9 なので、毎年 r ≈ 0.9 倍で減少していると推定できます。

r2 = 0.9

2両辺の常用対数をとる

この式 r2 = 0.9 を直接解くのは難しいです。そこで「常用対数」という道具を使います。

🔵 常用対数の意味（中学の知識）

常用対数とは「10を底とする対数」のこと。log₁₀ x は「10を何乗したら x になるか」という問いです。

  • log₁₀ 10 = 1　（10¹ = 10 だから）
  • log₁₀ 100 = 2　（10² = 100 だから）
  • log₁₀ 0.1 = −1　（10⁻¹ = 0.1 だから）

「対数をとる」とは、この「10を何乗したか」という指数を取り出す作業です。

log10(r2) = log10 0.9

3対数の性質で指数を前に出す

対数には便利な性質があります。

🔵 対数の性質：指数を前に出す

log₁₀(an) = n × log₁₀ a

つまり、指数 n は対数の前に出せます。例えば：

  • log₁₀(2³) = 3 × log₁₀ 2
  • log₁₀(r²) = 2 × log₁₀ r

これを使うと、r の対数だけを求めればよくなります。

2 log10 r = log10 0.9

4log₁₀ 0.9 を計算する

0.9 = 9/10 なので、商の対数を使います。

🔵 対数の性質：割り算は引き算に

log₁₀(A/B) = log₁₀ A − log₁₀ B

掛け算が足し算に変わるなら、割り算は引き算に変わります。例えば：

  • log₁₀ 0.1 = log₁₀(1/10) = log₁₀ 1 − log₁₀ 10 = 0 − 1 = −1
  • log₁₀ 0.9 = log₁₀(9/10) = log₁₀ 9 − log₁₀ 10 = log₁₀ 9 − 1
log10 0.9 = log10(9/10) = log10 9 − log10 10 ≈ 0.9542 − 1 = −0.0458
⚠️ テストで注意：負の値が出ることもある

対数は負の値になることがあります。0より小さい数（0 < x < 1）の対数は常に負です。これは「10を負の数乗すると小数になる」という意味です。

5log₁₀ r を求める

2 log₁₀ r = −0.0458 なので、両辺を 2 で割ります。

log10 r = −0.0458 ÷ 2 = −0.0229
✓ 答　log₁₀ r = −0.0229

（2）2034年と2014年の人口を求める

ヒント：（1）で求めた log₁₀ r ≈ −0.0229 を使います。

2034年の人口（10年後）

12034年の人口を式にする

2024年から2034年は10年後です。毎年 r 倍になるので、10年後は r を10回掛けます。

2034年の人口を s 万人とすると：

s = 100 × r10
🔵 なぜ r の10乗か

毎年 r 倍になるとき、n年後には rn 倍になります。10年後なら r10 です。これは「複合比率」で、実社会の複利計算や人口予測で使われます。

2両辺の対数をとり、対数の性質を使う

両辺の常用対数をとります。

log10 s = log10(100 × r10)

掛け算は足し算に分けられます。

🔵 対数の性質：掛け算は足し算に

log₁₀(A × B) = log₁₀ A + log₁₀ B

例えば：

  • log₁₀(10 × 100) = log₁₀(1000) = 3 = 1 + 2 = log₁₀ 10 + log₁₀ 100

これにより、複雑な掛け算が足し算になります。計算機がない時代、この性質で大きな数の計算ができました。

log10 s = log10 100 + log10(r10) = 2 + 10 log10 r

（1）から log₁₀ r ≈ −0.0229 なので：

log10 s ≈ 2 + 10 × (−0.0229) = 2 − 0.229 = 1.771

3対数から元の値を求める（逆対数）

log₁₀ s = 1.771 から、s を求めます。

🔵 対数の「逆」を求める

log₁₀ s = 1.771 は「10 を何乗したら s になるか」という意味なので：

s = 101.771

対数値が求まったら、対数表や計算機を使って「元の値」に戻します。log₁₀ s = 1.771 なら s = 101.771 です。この逆変換を忘れないで！

（3）人口が123万人を初めて超える年

新しい前提：2024年以降、人口は毎年 1.02倍で増加します。（これまでの減少から増加へ転換）

何年後に123万人を超えるか

1n年後の人口を式にする

2025年を1年後とします。2025年の人口は102万人で、毎年 1.02倍に増加します。

n年後の人口 = 102 × 1.02n−1
🔵 「n年後」を正確に定義する

「2025年を1年後とする」というのは、カウント開始のルール決めです。

  • 1年後（2025年）：102 × 1.02⁰ = 102万人
  • 2年後（2026年）：102 × 1.02¹ = 102 × 1.02万人
  • n年後：102 × 1.02n−1 万人

このように、「1年後」から数え始めることで、式が正確になります。

この人口が123万人を超える条件は：

102 × 1.02n−1 > 123

2不等式を整理する

両辺を102で割ります。

1.02n−1 > 123/102 ≈ 1.20588
⚠️ テストで注意：不等式は両辺を割っても向きは変わらない

正の数で両辺を割っても、不等号の向き（> や <）は変わりません。ただし負の数で割ると向きが反対になります！

3両辺の対数をとる

両辺の常用対数をとります。対数は「増加する関数」なので、不等号の向きは変わりません。

(n−1) log10 1.02 > log10 1.20588
🔵 対数関数の性質

対数は「単調増加関数」です。つまり、A > B なら log₁₀ A > log₁₀ B です。（底が1より大きい場合）

不等号の向きが保たれるのはこのためです。

対数表から：

log10 1.02 ≈ 0.0086
log10 1.20588 ≈ 0.0813

4n を求める

(n−1) × 0.0086 > 0.0813
n−1 > 0.0813 ÷ 0.0086 ≈ 9.45
n > 10.45
🔵 不等式の整数解を見つける

n > 10.45 を満たす最小の整数は何か？ 10.45より大きい最小の整数は 11 です。

つまり、11年後に初めて123万人を超えます。

⚠️ テストで注意：不等式の答えと具体値の検証

不等式を解いても、実際に満たすかどうかを具体値で確認することが大切です。

二階導関数

f″(x) を求める

関数 f(x) = x3 − 3x2 + x について、f″(x) を求めよ。

(xn)′ = n·xn−1　（定数を微分すると 0） 二階導関数：f″(x) = (f′(x))′　（f′(x) をもう一度微分する）

各項は、3x2 → 6x、−6x → −6、1 → 0（定数は消える）と微分していきます。

接線

点 (−1, f(−1)) における接線 ℓ

C 上の点 (−1, f(−1)) における接線を ℓ とするとき、ℓ の方程式を求めよ。

点 (a, f(a)) における接線：y − f(a) = f′(a)(x − a) 必要なもの：接点の座標 (a, f(a)) と 傾き f′(a)
① 接点：f(−1) = (−1)3 − 3(−1)2 + (−1) = −1 − 3 − 1 = −5　⇒　接点は (−1, −5) ② 傾き：f′(−1) = 3(−1)2 − 6(−1) + 1 = 3 + 6 + 1 = 10 ③ 接線：y − (−5) = 10{x − (−1)}　⇒　y + 5 = 10(x + 1)　⇒　y = 10x + 5

f′(x) のグラフの対称軸と、ℓ に平行な別の接線

平行移動・接する条件

y軸方向に d だけ平行移動した曲線 C′ が ℓ に接する

C を y軸方向に d だけ平行移動した曲線 C′ が ℓ と接するとき、d を求めよ。ただし d は 0 でない実数とする。

y軸方向に d だけ平行移動：y = f(x) + d 曲線と直線が x = p で接する ⇔ p で「y座標も傾きも等しい」
C′：y = x3 − 3x2 + x + d。C′ の傾きは (f(x) + d)′ = f′(x)　（d は微分すると消える） ℓ（傾き 10）と接する点では C′ の傾きも 10 なので　f′(x) = 10　⇒　x = −1, 3　（(3) と同じ） (i) x = −1 のとき：C′ の y座標 f(−1) + d = −5 + d、ℓ の y座標 10(−1) + 5 = −5　⇒　d = 0　（d ≠ 0 に反するので不適） (ii) x = 3 のとき：C′ の y座標 f(3) + d = 3 + d、ℓ の y座標 10·3 + 5 = 35　⇒　3 + d = 35　⇒　d = 32
やさしい解説：なぜ x = 3 を使うの？
  • C を上下にずらしても、各 x での傾きは変わりません（形を保ったまま動かすだけ）。だから、傾き 10 の点は x = −1 と x = 3 のまま。
  • x = −1 を使うと d = 0（動かさないこと）になり、問題の「d は 0 でない」に反します。だから x = 3。
  • x = 3 で C′ の高さ（3 + d）が ℓ の高さ（35）にちょうど重なるように、C を 32 だけ上へ動かします。
検算（重解を使う方法）：C′ と ℓ の式を連立すると x3 − 3x2 + x + d = 10x + 5　⇒　x3 − 3x2 − 9x + (d − 5) = 0。接する ⇔ この方程式が重解をもつ。
d = 32 のとき　x3 − 3x2 − 9x + 27 = (x − 3)2(x + 3)：x = 3 が重解（接点）✓、x = −3 は別の交点です。また f′(3) = 27 − 18 + 1 = 10 で、傾きも ℓ と一致しています ✓。
テストのポイント：「接する」は「y座標が等しい」だけでなく「傾きも等しい」ことまで使います。傾きの条件で接点の候補（x = −1, 3）をしぼり、y座標の条件で d を決める、という順番です。
答 〔1〕(4)d = 32

a, b を正の定数とし、g(x) = ax2 + b とする。g(x) の対称性と、対称な区間の定積分について調べよ。

積分で定義された関数

h(t) の増減と、左右の面積が等しくなる t

h(t) = ∫t−1g(x)dx について、(i) h(t) の増減を調べよ。(ii) ∫t−1g(x)dx = ∫1tg(x)dx（−1 ≦ t ≦ 0）となる t を求めよ。

(i) h(t) の増減

等比数列への変形

数列 {aₙ} の一般項

数列 {an} は a1 = 8、an+1 = 2an + 8 を満たす。一般項を求めよ。

① 特性方程式 α = pα + q を解いて α を求める（この問題では α = 2α + 8 ⇒ α = −8） ② an+1 − α = p(an − α)　⇒　{an − α} は公比 p の等比数列 等比数列の一般項：un = u1 · rn−1
an+1 + 8 = 2an + 8 + 8 = 2an + 16 = 2(an + 8) un = an + 8 とおくと　un+1 = 2un　⇒　{un} は公比 2 の等比数列 初項　u1 = a1 + 8 = 16　より　un = 16 · 2n−1 = 24 · 2n−1 = 2n+3 an + 8 = 2n+3　⇒　an = 2n+3 − 8
やさしい解説：なぜ「an ＋ 8」に注目するの？

漸化式 an+1 = 2an + 8 は、「2倍して 8 を足す」というルールです。この「＋8」が邪魔で、そのままでは等比数列になりません。

そこで、動かない値 α（an+1 = an = α になる値）を探します。α = 2α + 8 を解くと α = −8。この −8 を引く（つまり ＋8 する）と、「＋8」がうまく消えて、an+1 + 8 = 2(an + 8) という「2倍するだけ」の形になります。

テストのポイント：①等比数列の一般項は u1 · rn−1（n−1 乗）。②16 · 2n−1 = 24 · 2n−1 = 2n+3 は、指数のたし算（4 + (n−1) = n + 3）。③最後に＋8 を戻す（−8 する）のを忘れない。

(2) 領域 D

（x² + y² − 1）と（x² + y² − 4x − 2y + 1）の積が 0 以下 ⇔ 一方が 0（円周上），または 2つの符号が逆 f₁ = x² + y² − 1 ＝ 0 は C₁ の円周，f₁ ≤ 0 は C₁ の内側（円盤の内部） f₂ ≤ 0 は C₂ の内側，f₂ ≥ 0 は C₂ の外側
やさしい解説：「片方の内側・もう片方の外側」

2つの数の積が 0 以下になるのは、「一方が 0」か「符号が逆」のときです。つまり、C₁ の内側かつ C₂ の外側、または C₂ の内側かつ C₁ の外側の部分です。2つの円が重なった部分は、どちらも内側なので積は正になり、含まれません。

円周上は積が 0 になるので、円周も含まれます。

テストのポイント：「≤ 0」は、円周を含む。また「重なった部分は除く」ことを、図で必ず確認する。

(3) 直線と領域 D が交わる条件

円周は D に含まれる。直線が C₁ か C₂ のどちらかと交わるなら、その交点は D の中にある。 逆に、どちらの円とも交わらない直線は、2つの円の外側だけを通るので、D とは交わらない。 よって「C₁ と交わる」または「C₂ と交わる」の範囲を合わせればよい。
やさしい解説：なぜ円と交われば十分？

直線は円盤の中だけを通ることはできません（まっすぐ伸びて外に出るから）。直線が2つの円のどちらとも交わらなければ、直線全体は円の外にあるので、D にも入りません。

逆に、円と交わればその交点は円周上の点で、円周は D に含まれます。

円の中心から直線までの距離 ≤ 半径 直線は mx − y − m − 2 = 0（y = m(x − 1) − 2 を変形）。点と直線の距離の公式を使う。
