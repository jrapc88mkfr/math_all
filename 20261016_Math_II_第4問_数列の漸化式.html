数学Ⅱ 第4問

数列の漸化式

数列 {an} は初項が 8 で、an+1 = 2an + 8（n = 1, 2, 3, …）を満たす。また、数列 {bn} は初項が 0 で、bn+1 = 6bn + an（n = 1, 2, 3, …）を満たす。次の問いに答えよ。 (1) b2, b3 を求めよ。 (2) 数列 {an} の一般項を求めよ。 (3) 数列 {bn} の一般項を求めよ。

(1)　漸化式に n = 1, 2 を順に入れて、次の項をつくる (2)　an ＋ 8 に注目 → 等比数列になる (3)　an を代入 → 特解 f(n) を引く → dn = bn − f(n) が等比数列になる
この問題の合言葉：「漸化式は次の項をつくるルール」「一般項を求めるには等比数列に直す」「(2) は定数を足す、(3) は特解を引く」。
(1)
漸化式の計算

b₂, b₃ を求める

b2, b3 を求めよ。

bn+1 = 6bn + an　に　n = 1, 2 を順に入れる n = 1：b2 = 6b1 + a1　　n = 2：b3 = 6b2 + a2
a1 = 8 より　a2 = 2a1 + 8 = 2 × 8 + 8 = 24 b1 = 0 より　b2 = 6b1 + a1 = 6 × 0 + 8 = 8 b3 = 6b2 + a2 = 6 × 8 + 24 = 72
やさしい解説：漸化式は「次の項をつくるルール」

bn+1 = 6bn + an は、「今の b を 6 倍して、同じ番号の a を足すと、次の b になる」というルールです。数を入れていけば、項が順番に出てきます。

b を計算するには a も必要なので、先に a2 も計算しておきます。

テストのポイント：b3 に使うのは a2（a3 ではない）。bn+1 の式に出てくる a は、1つ前の番号のan です。添え字（n）を取り違えないこと。

答 (1)b2 = 8，b3 = 72
(2)
等比数列への変形

数列 {aₙ} の一般項

数列 {an} は a1 = 8、an+1 = 2an + 8 を満たす。一般項を求めよ。

① 特性方程式 α = pα + q を解いて α を求める（この問題では α = 2α + 8 ⇒ α = −8） ② an+1 − α = p(an − α)　⇒　{an − α} は公比 p の等比数列 等比数列の一般項：un = u1 · rn−1
an+1 + 8 = 2an + 8 + 8 = 2an + 16 = 2(an + 8) un = an + 8 とおくと　un+1 = 2un　⇒　{un} は公比 2 の等比数列 初項　u1 = a1 + 8 = 16　より　un = 16 · 2n−1 = 24 · 2n−1 = 2n+3 an + 8 = 2n+3　⇒　an = 2n+3 − 8
やさしい解説：なぜ「an ＋ 8」に注目するの？

漸化式 an+1 = 2an + 8 は、「2倍して 8 を足す」というルールです。この「＋8」が邪魔で、そのままでは等比数列になりません。

そこで、動かない値 α（an+1 = an = α になる値）を探します。α = 2α + 8 を解くと α = −8。この −8 を引く（つまり ＋8 する）と、「＋8」がうまく消えて、an+1 + 8 = 2(an + 8) という「2倍するだけ」の形になります。

テストのポイント：①等比数列の一般項は u1 · rn−1（n−1 乗）。②16 · 2n−1 = 24 · 2n−1 = 2n+3 は、指数のたし算（4 + (n−1) = n + 3）。③最後に＋8 を戻す（−8 する）のを忘れない。
検算：n = 1：24 − 8 = 8 ✓　n = 2：25 − 8 = 24 ✓（漸化式の 2 × 8 + 8 = 24 と一致）　n = 3：26 − 8 = 56 ✓（2 × 24 + 8 = 56）。
答 (2)an = 2n+3 − 8
(3)
特解を引いて等比数列に

数列 {bₙ} の一般項

数列 {bn} は b1 = 0、bn+1 = 6bn + an を満たす。一般項を求めよ。

①　漸化式だけを満たす特解 f(n) を1つ見つける：f(n+1) = 6f(n) + an ②　dn = bn − f(n) とおくと　dn+1 = 6dn（等比数列） ③　bn = dn + f(n)

STEP 0　an を代入する

(2) より an = 2n+3 − 8 なので　bn+1 = 6bn + 2n+3 − 8

STEP 1　特解 f(n) を求める

右辺に 2n の項と定数があるので、f(n) = p · 2n + q とおき、f(n+1) = 6f(n) + 2n+3 − 8 に代入する。 p · 2n+1 + q = 6(p · 2n + q) + 8 · 2n − 8　　（2n+3 = 8 · 2n） 2n の係数を比べて　2p = 6p + 8　⇒　p = −2 定数項を比べて　q = 6q − 8　⇒　−5q = −8　⇒　q = 85 f(n) = −2 · 2n + 85 = −2n+1 + 85
やさしい解説：特解って何？

特解は、「初項は気にしないで、漸化式のルールだけを満たす式を1つ見つけたもの」です。bn+1 = 6bn + (2n+3 − 8) の右側に「2n の形」と「定数」があるので、特解も同じ形 p · 2n + q と予想します。

予想の式を代入して、2n の係数どうしと定数どうしを比べると、p と q が決まります（係数比較）。

STEP 2　dn = bn − f(n) が等比数列になる

bn+1 = 6bn + an　…①　　f(n+1) = 6f(n) + an　…② ① − ② より　bn+1 − f(n+1) = 6(bn − f(n))　⇒　dn+1 = 6dn よって {dn} は公比 6 の等比数列。初項は d1 = b1 − f(1) = 0 − ( −4 + 85 ) = 0 − ( −125 ) = 125 したがって　dn = 125 · 6n−1
やさしい解説：なぜ引くと an が消える？①と②は、どちらも「6 倍して an を足す」という同じルールです。だから①から②を引くと、an の部分がちょうど打ち消し合って、「6 倍するだけ」の関係 dn+1 = 6dn が残ります。

STEP 3　bn を求める

bn = dn + f(n) = 125 · 6n−1 − 2n+1 + 85 ここで　125 · 6n−1 = 125 × 6 · 6n = 25 · 6n bn = 25 · 6n − 2n+1 + 85

FINAL CHECK

ここだけ確認

超重要・一言で覚える：「定数が付いた漸化式は動かない値 α を引いて等比数列に」「2n が付いた漸化式は特解 f(n) を引いて等比数列に」。
  1. (1) 項の計算：a2 = 2 × 8 + 8 = 24、b2 = 6 × 0 + 8 = 8、b3 = 6 × 8 + 24 = 72。（b₃ に使う a は a₂）
  2. (2) an：an+1 + 8 = 2(an + 8)。初項 a1 + 8 = 16、公比 2 → an + 8 = 2n+3 → an = 2n+3 − 8。
  3. (3) 特解：f(n) = p · 2n + q を f(n+1) = 6f(n) + 2n+3 − 8 に代入し、係数比較で p = −2，q = 85。
  4. (3) 等比数列：dn = bn − f(n) は公比 6、初項 d1 = 125 → dn = 125 · 6n−1。
  5. (3) 答え：bn = dn + f(n) = 25 · 6n − 2n+1 + 85。n = 1, 2, 3 を入れて 0, 8, 72 になれば合っている。
