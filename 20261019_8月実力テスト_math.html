数学Ⅰ・数と式

因数分解：x の2次式として見る

x² + 5(y + 1)x + 6y² + 11y + 4 を因数分解せよ。

x について見ると x² + (・)x + (・) の形の2次式。定数項 6y² + 11y + 4 を2つの式の積に分けて、掛けて定数項、足して x の係数になるようにする。
6y² + 11y + 4 = (2y + 1)(3y + 4) (2y + 1) + (3y + 4) = 5(y + 1) よって　(x + 2y + 1)(x + 3y + 4)
やさしい解説：なぜ 2y+1 と 3y+4 を選ぶの？

(x + p)(x + q) を展開すると x² + (p + q)x + pq になります。今回は p + q = 5(y + 1)、pq = 6y² + 11y + 4 を満たす p, q を探します。

6y² + 11y + 4 を (2y + 1)(3y + 4) と分けると、2y + 1 + 3y + 4 = 5y + 5 = 5(y + 1) になり、ちょうど真ん中の係数と一致します。

テストのポイント：答えを展開して元の式と一致するか確かめる習慣をつけましょう。(x + 2y + 1)(x + 3y + 4) を展開すると、x² + (5y + 5)x + (2y + 1)(3y + 4) となり、元の式と一致します ✓。
答 (1)(x + 2y + 1)(x + 3y + 4)

数学Ⅰ・二次関数

平行移動：x を x − 2 に、全体から 1 を引く

二次関数 y = 2x² − 4x + 4 のグラフを、x軸方向に 2、y軸方向に −1 だけ平行移動したグラフの方程式を求めよ。

x軸方向に p、y軸方向に q だけ移動 ⇒ y − q = f(x − p) 今回は p = 2、q = −1 なので　y + 1 = f(x − 2)　⇒　y = f(x − 2) − 1
y = 2(x − 2)² − 4(x − 2) + 4 − 1 = 2(x² − 4x + 4) − 4x + 8 + 3 = 2x² − 8x + 8 − 4x + 11 = 2x² − 12x + 19
やさしい解説：「右へ2」は x を x − 2 に

グラフを右へ動かすと、同じ形の山（谷）が右側に移ります。例えば「x = 1 で最小だった放物線」が右へ 2 動くと、「x = 3 で最小」になります。そのため、式の中の x に x − 2 を代入します（x に −2 を足すと左へ、＋2 を足すと右へ動く、とは逆なので注意）。

「下へ1」は、式全体から 1 を引くだけです。

検算：頂点で確かめると、元の頂点 (1, 2) を右へ 2、下へ 1 動かすと (3, 1)。移動後の式 2x² − 12x + 19 = 2(x − 3)² + 1 の頂点も (3, 1) で一致 ✓。
テストのポイント：「右へ 2」は x → x − 2。符号を逆にして x + 2 とすると誤りです。また、y方向の移動は式の外側（全体）に作用します。
答 (2)y = 2x² − 12x + 19

数学Ⅰ・加法定理

加法定理で cos を1つにまとめる

cos 40° cos 140° − sin 40° cos 50° を求めよ。

cos(α + β) = cos α cos β − sin α sin β sin(α + β) = sin α cos β + cos α sin β 引き算の形（β を −β と考える）：cos(α − β) = cos α cos β + sin α sin β，sin(α − β) = sin α cos β − cos α sin β
やさしい解説：式の形を加法定理に合わせる

問題の式は cos 40° cos 140° − sin 40° cos 50° です。加法定理の cos α cos β − sin α sin β の形に似ていますが、2つ目の項の角が 40° と 50° で揃っていません。

そこで、cos 50° と sin 40° をそれぞれ加法定理で書き換え、2つの角を揃えます。

STEP 1　cos 50° を sin 40° にする

cos 50° = cos(90° − 40°) = cos 90° cos 40° + sin 90° sin 40° cos 90° = 0、sin 90° = 1 より　= 0 + 1 · sin 40° = sin 40° よって　cos 50° = sin 40°

STEP 2　sin 140° を sin 40° にする

sin 140° = sin(180° − 40°) = sin 180° cos 40° − cos 180° sin 40° sin 180° = 0、cos 180° = −1 より　= 0 · cos 40° − (−1) · sin 40° = sin 40° よって　sin 140° = sin 40°

STEP 3　式を書き直す

cos 40° cos 140° − sin 40° cos 50° = cos 40° cos 140° − sin 40° · sin 40°　（STEP 1 より cos 50° = sin 40°） = cos 40° cos 140° − sin 40° · sin 140°　（STEP 2 より sin 40° = sin 140°）

STEP 4　加法定理でまとめる

cos 40° cos 140° − sin 40° sin 140° = cos(40° + 140°)　（加法定理 cos(α + β) の形） = cos 180° = −1
やさしい解説：なぜ「cos(40°+140°)」になる？

加法定理 cos(α + β) = cos α cos β − sin α sin β を右から左へ読みます。α = 40°、β = 140° とすると、右辺は cos 40° cos 140° − sin 40° sin 140° になり、STEP 3 で作った式と同じ形です。

つまり、式を加法定理の右辺の形に直してから、左辺にまとめるのがこの問題の流れです。cos 180° は単位円で x 座標が −1 の点なので、−1 になります。

テストのポイント：問題の式を見て「cos α cos β − sin α sin β の形になっていないか」を確かめる。なっていなければ、角を揃える（cos 50° → sin 40°、sin 40° → sin 140°）で形を作る。最後に cos(α + β) の値を、単位円や特別な角で求める。
検算（数値）：cos 40° ≒ 0.7660、cos 140° ≒ −0.7660、sin 40° ≒ 0.6428、sin 140° ≒ 0.6428。
cos 40° cos 140° − sin 40° sin 140° ≒ −0.5868 − 0.4132 = −1.0000 ✓（cos 180° = −1 と一致）
答 (3)−1（加法定理 cos(40° + 140°) = cos 180° を使う）

数学Ⅰ・図形と計量

余弦定理と、角の二等分線の長さ

△ABC において、AB = 6，AC = 8，∠A = 60° とする。 (i) BC の長さを求めよ。 (ii) ∠A の二等分線と BC との交点を D とするとき、AD の長さを求めよ。

(i) BC の長さ（余弦定理）

a² = b² + c² − 2bc cos A　（a は向かい側の辺、b, c は A をはさむ2辺）
BC² = 6² + 8² − 2 · 6 · 8 · cos 60° = 36 + 64 − 48 = 52 BC は正なので　BC = 2√13
やさしい解説：三平方の定理の一般形

直角三角形なら a² = b² + c² ですが、角が 90° でないときは、−2bc cos A の補正が加わります。cos 90° = 0 なので、直角のときは補正が消えて三平方の定理と同じになります。

(ii) AD の長さ（角の二等分線の長さの公式）

AD² = bc [ 1 − a² / (b + c)² ]　（b = AC，c = AB，a = BC）
AD² = 6 · 8 [ 1 − (2√13)² / (6 + 8)² ] = 48 (1 − 52/196) = 48 · 144/196 = 1728/49 AD は正なので　AD = 24√3 / 7
やさしい解説：二等分線の長さの公式はどこから？

三角形 ABD と ACD に分けて、余弦定理を使うと出てきます。どちらも ∠A の半分（30°）を角に持つので、「角の半分の cos」を使うと、もう1つの形の公式にもなります（検算に使えます）。

検算（別の公式）：AD ＝ 2bc cos(A/2) / (b + c) ＝ 2 · 6 · 8 · cos 30° / 14 ＝ 96 · (√3/2) / 14 ＝ 48√3 / 14 ＝ 24√3 / 7 ✓。
テストのポイント：公式の b, c は A をはさむ2辺（AC と AB）。a は向かい側の辺 BCです。b と c を入れかえても結果は同じですが、a を取り違えると誤りになります。また、「長さは正」なので √ の前の符号に注意。
答 (4)(i) BC = 2√13　　(ii) AD = 24√3/7

別解：三角形の面積を使う方法

∠A の二等分線だから　∠BAD = ∠DAC = 30° △ABC ＝ △ABD ＋ △ADC △ABD ＝ (1/2)·AB·AD·sin 30°，　△ADC ＝ (1/2)·AC·AD·sin 30° よって　△ABC ＝ (1/2)·AD·sin 30°·(AB + AC) ＝ (1/2)·AD·(1/2)·14 ＝ (7/2)AD 一方　△ABC ＝ (1/2)·6·8·sin 60° ＝ 12√3 12√3 = (7/2)AD　より　AD = 24√3/7
やさしい解説：面積で「辺の長さ × 辺の長さ × sin」を使う

三角形の面積は「2辺 × その間の角の sin × 1/2」で求められます。△ABC を、点 D を通る線で △ABD と △ADC の2つに分けると、どちらも頂点 A から出る辺 AD を共有しています。

∠A を二等分しているので、2つの三角形の角はどちらも 30°。sin 30° = 1/2 を使うと、式がシンプルになります。

テストのポイント：面積の式は「2辺とその間の角」で書くのがコツ。分け方を図に書いて、どの角を使うかを確認しましょう。

数学Ⅰ・データの分析

y = −2x + 3 のときの平均と分散

変量 x の平均が 21、分散が 12 である。y = −2x + 3 とするとき、変量 y の平均と分散を求めよ。

平均：ȳ = a·x̄ + b　（x̄ は x の平均） 分散：s_y² = a² s_x²　（b は分散に影響しない）
平均　ȳ = −2 × 21 + 3 = −39 分散　V(y) = (−2)² × 12 = 48
やさしい解説：なぜ分散は b を無視するの？

全部の値に同じ数を足しても、「平均からのズレ」は変わりません。例えば、どの点数にも 3 点を足すと、平均は 3 点上がりますが、一人ひとりの平均との差はそのままです。だから分散は変わりません。

一方、−2 倍すると、ズレも 2 倍になります。分散は「ズレの2乗の平均」なので、(−2)² = 4 倍になります。

テストのポイント：平均は「そのまま代入」、分散は「定数の2乗倍」。分散に「+3」を足さないこと、また「−2」を2乗して「+4」にすることを確認しましょう。
答 (5)平均 −39，　分散 48

数学Ⅱ・解と係数の関係

2解の比が 2 : 3 となる m の値

2次方程式 x² − (m − 1)x + m = 0 の2解の比が 2 : 3 であるとき、m の値を求めよ。

2次方程式 ax² + bx + c = 0 の2解を α, β とすると α + β = −b/a，　αβ = c/a 例：x² + 3x + 2 = 0 では　a = 1，b = 3，c = 2　⇒　和 ＝ −3，積 ＝ 2 （確認：(x + 1)(x + 2) = 0 より解は −1，−2。和 −3、積 2 で一致 ✓） この問題（a = 1）では　和 ＝ m − 1，積 ＝ m
2解を 2k，3k とおく。解と係数の関係より 2k + 3k = m − 1 より　m = 5k + 1　…① 2k · 3k = m より　6k² = m　…② ①を②に代入して　6k² = 5k + 1　⇒　6k² − 5k − 1 = 0 (6k + 1)(k − 1) = 0　⇒　k = 1，−1/6 k = 1 のとき m = 6，　k = −1/6 のとき m = 1/6 よって　m = 6，1/6
やさしい解説：「比」を文字で表す

2 : 3 の比は、「2 と 3 の倍率が同じ」という意味です。そこで、2解を 2k，3k と置くと、比が自動的に 2 : 3 になります。k は「1 あたりの大きさ」のようなものです。

このように、「未知数を1つ増やして、条件を式にする」のが比の問題の定番です。

検算：m = 6 のとき、x² − 5x + 6 = 0、解は 2 と 3 で比は 2 : 3 ✓。m = 1/6 のとき、6x² + 5x + 1 = 0、解は −1/2，−1/3。絶対値の比は 1/2 : 1/3 = 3 : 2、逆向きの 2 : 3 と同じ組み合わせ ✓。
テストのポイント：k の値が2つ出たとき、両方が条件を満たすか確認する。また、解が負の数のときは、比を「符号を除いた大きさ」で考えるのがふつうです。答えは m = 6，1/6 の2つ。
答 (6)m = 6，　1/6

数学A・確率

5回の積が 3 の倍数になる確率（余事象）

サイコロを5回投げる。出た目の積を X とする。X が 3 で割り切れる確率を求めよ。

P(A) = 1 − P(Aの余事象) 「積が 3 で割り切れる」の余事象は「積が 3 で割り切れない」。
X が 3 で割り切れない ⇔ 5回とも 3 の倍数（3 と 6）が出ない ⇔ 5回とも 1, 2, 4, 5 のいずれか 1回で 3 の倍数以外が出る確率は 4/6 ＝ 2/3。各回は独立なので P(3 で割り切れない) = (4/6)⁵ = (2/3)⁵ = 32/243 よって　P(3 で割り切れる) = 1 − 32/243 = 211/243
注意：分数は先に約分してから計算する。4/6 は 2/3 に約分してから5乗すると、(2/3)⁵ ＝ 2⁵/3⁵ ＝ 32/243 と、数字が小さく済みます。約分せずに (4/6)⁵ のまま計算すると、途中の数が大きくなり、計算ミスの原因になります。
やさしい解説：「割り切れる」を直接数えるのは大変

積が 3 で割り切れるのは、「5回のうち少なくとも1回は 3 か 6 が出る」ときです。1回だけ、2回だけ、と場合分けすると、とても長くなります。

そこで、反対（割り切れない）の場合を考えます。「割り切れない」は「どの回も 3 と 6 が出ない」という1つの条件なので、かけ算で計算できます。

テストのポイント：「積が 3 の倍数」⇔「3 の因数が少なくとも1回」なので、3 と 6 が出ることがポイント。「1, 2, 4, 5 を選ぶ」の5回分の積を忘れずに。「1 − 余事象」の形で答えを書くと、途中式も伝わりやすくなります。
検算：1回で 3 か 6 が出る確率は 2/6 = 1/3。5回のうち少なくとも1回出る確率は 1 − (2/3)⁵ = 1 − 32/243 = 211/243 ✓。
答 (7)211/243

数学Ⅱ・円

円の中心と、円周上の点における接線

円 x² + y² + 6x − 6y + 5 = 0 について、 (i) 中心の座標を求めよ。 (ii) 点 (−1, 0) における接線の方程式を求めよ。

(i) 中心の座標（平方完成）

(x − a)² + (y − b)² = r²　中心 (a, b)，半径 r
x² + 6x + y² − 6y + 5 = 0 (x + 3)² − 9 + (y − 3)² − 9 + 5 = 0 (x + 3)² + (y − 3)² = 13 よって中心は　(−3, 3)（半径 √13）
やさしい解説：平方完成で中心を出す

x の項 x² + 6x は (x + 3)² − 9、y の項 y² − 6y は (y − 3)² − 9 に直せます。定数項をまとめると −9 − 9 + 5 = −13 なので、右辺に移すと 13 になります。

(ii) 点 (−1, 0) における接線

2点 (x₁, y₁)，(x₂, y₂) を通る直線の傾き：m = (y₂ − y₁) / (x₂ − x₁) 点 (x₁, y₁) を通り傾き m の直線：y − y₁ = m(x − x₁) 例：(1, 2) と (3, 6) を通る直線　⇒　m = (6 − 2)/(3 − 1) = 2　⇒　y − 2 = 2(x − 1)　⇒　y = 2x
円の接線は、接点を通る半径に垂直。 垂直な2直線の傾きの積 = −1（傾きが m のとき、垂直な直線の傾きは −1/m）
STEP 1　直線 CP の式（C(−3, 3)，P(−1, 0) の2点を通る） 傾き ＝ (0 − 3)/(−1 + 3) = −3/2　より　y − 0 = −3/2 (x + 1) 両辺に 2 をかけて　2y = −3x − 3　よって　直線 CP：3x + 2y + 3 = 0 （確認：C を代入 −9 + 6 + 3 = 0 ✓、P を代入 −3 + 0 + 3 = 0 ✓） STEP 2　接線（CP に垂直で、P(−1, 0) を通る直線） CP の傾きが −3/2 なので、垂直な接線の傾きは　−1 ÷ (−3/2) = 2/3 点 (−1, 0) を通るので　y = (2/3)(x + 1)　両辺に 3 をかけて　3y = 2x + 2 よって　2x − 3y + 2 = 0
やさしい解説：なぜ傾きを「逆数で符号反対」にする？

傾きが −3/2 の線（急に右下がり）に直角に交わる線は、右上がりの緩やかな線になります。傾きは −1/(−3/2) = 2/3 です。

直角に交わる2本の線は、「傾きどうしを掛けると −1 になる」と覚えておきましょう。

検算：点 (−1, 0) が円上にあるか確認：(−1)² + 0² + 6(−1) − 6 · 0 + 5 = 1 − 6 + 5 = 0 ✓。接線 2x − 3y + 2 = 0 に (−1, 0) を代入すると −2 + 0 + 2 = 0 ✓。
テストのポイント：接線の問題は「接点が円上にあるか」を最初に確かめる。円の外の点からの接線は、この方法では求められません（別の解き方が必要）。今回の点は円周上なので、中心との傾きで求められます。
確認ポイント：接線は半径と垂直です。点 (−1, 0) はこの円周上にあるため、その点での接線を求められます。
答 (8)(i) 中心 (−3, 3)　　(ii) 2x − 3y + 2 = 0
